# windows-batch

Colección de scripts .bat para uso educativo y utilidades básicas en Windows.

## Scripts incluidos
- `ordenpor.bat` - Lista archivos ordenados por nombre, extensión o tamaño.
- `ver-archivos.bat` - Muestra el contenido de archivos `.txt` y `.bat` del directorio.

## Uso
Abrir una consola en la carpeta y ejecutar:
- `ordenpor.bat`
- `ver-archivos.bat`

**Advertencia:** Estos scripts son educativos y no realizan acciones peligrosas. Ejecutarlos localmente es seguro.
