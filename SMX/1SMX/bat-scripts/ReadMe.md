# 🐚 Windows Batch Collection: OS Automation & Utils
# 🐚 Colección Windows Batch: Automatización y Utilidades

## 📋 Overview | Resumen de Proyecto

A practical collection of `.bat` scripts developed during **1SMX** to master OS-level automation and command-line utilities. These scripts focus on file management, conditional logic (`IF`), and interactive user input in Windows environments.

Una colección práctica de scripts `.bat` desarrollados durante **1SMX** para dominar la automatización a nivel de SO y las utilidades de línea de comandos. Estos scripts se centran en la gestión de archivos, lógica condicional (`IF`) y entrada interactiva del usuario en entornos Windows.

---

## 🛠️ Utility Scripts | Scripts de Utilidad

- **`ordenpor.bat`**: Dynamically lists files sorted by Name, Extension, or Size based on user input. | *Lista dinámicamente archivos ordenados por Nombre, Extensión o Tamaño según la entrada del usuario.*
- **`Ver archivos.bat`**: Safely displays the contents of text (`.txt`) and script (`.bat`) files within the current directory. | *Muestra de forma segura el contenido de archivos de texto (`.txt`) y scripts (`.bat`) en el directorio actual.*
- **`existe.bat`**: A logic check script that verifies file existence and handles conditional output. | *Un script de comprobación lógica que verifica la existencia de archivos y maneja salidas condicionales.*
- **`Juego M2.bat`**: A basic interactive game logic implemented entirely in Batch. | *Lógica de juego interactiva básica implementada íntegramente en Batch.*

---

## 🛠️ Tech Stack | Tecnologías

- **Shell:** Windows Command Prompt (CMD)
- **Language:** Batch Scripting
- **Concepts:** Environment variables, loop processing, conditional branching.

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open **Command Prompt** (cmd.exe) or **PowerShell**. | *Abre el **Símbolo del sistema** o **PowerShell**.*
2.  Navigate to this directory. | *Navega hasta este directorio.*
3.  Execute any script by typing its name: `ordenpor.bat`. | *Ejecuta cualquier script escribiendo su nombre.*
