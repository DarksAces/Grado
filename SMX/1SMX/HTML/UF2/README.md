# 🌐 SMX HTML/CSS: Intermediate Web Layouts (UF2)
# 🌐 SMX HTML/CSS: Maquetación Web Intermedia (UF2)

## 📋 Overview | Resumen de Proyecto

A series of web development practices designed to master **HTML5** and **CSS3** layout techniques. Developed during the **1st year of SMX (UF2)**, these exercises focus on semantic structure, navigation systems, and interactive menus.

Una serie de prácticas de desarrollo web diseñadas para dominar las técnicas de maquetación en **HTML5** y **CSS3**. Desarrolladas durante el **1er año de SMX (UF2)**, estos ejercicios se enfocan en la estructura semántica, sistemas de navegación y menús interactivos.

---

## ✨ Key Features | Características Clave

- **Dynamic Menus:** Specialized CSS layouts for navigation bars and dropdown systems. | *Menús Dinámicos: Diseños CSS especializados para barras de navegación.*
- **Hyperlink Management:** Structured cross-linking between multiple HTML pages (`Menu.html`, `Cerveza.html`). | *Gestión de Enlaces: Vinculación estructurada entre múltiples páginas HTML.*
- **Semantic Structure:** Proper use of `<nav>`, `<ul>`, and `<li>` elements for accessible web architecture. | *Estructura Semántica: Uso adecuado de elementos HTML5 para una arquitectura web accesible.*
- **Visual Styling:** Exploration of CSS properties for hovering effects and layout alignment. | *Estilado Visual: Exploración de propiedades CSS para efectos hover y alineación.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** HTML5, CSS3.
- **Concepts:** Box Model, Positioning, Flexbox basics.

---

## 📂 Project Structure | Estructura del Proyecto

- **`Menu.html`**: The primary navigation dashboard. | *El dashboard de navegación principal.*
- **`Cerveza.html`**: Thematic content page demonstrating secondary linking. | *Página de contenido temático que demuestra enlaces secundarios.*
- **`Tercera opcion.html`**: Additional layout experiments. | *Experimentos de maquetación adicionales.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open `Menu.html` in any modern web browser. | *Abre `Menu.html` en cualquier navegador web moderno.*
2.  Use the navigation links to explore the different sections of the project. | *Usa los enlaces de navegación para explorar las secciones.*
