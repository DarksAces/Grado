# 🌐 1SMX Fundamentos Web: Inmersión en HTML5 y CSS3 Hub

## 📋 Overview | Visión General

Welcome to the **1SMX HTML Foundations Hub**. This directory orchestrates the first immersion into the world of Web Development. The curriculum is structured to build a mastery of **Semantic HTML5** and foundational **CSS3** layout orchestration. From basic menu creation in the early units (UF2-UF3) to the creation of interactive forms and complex exam prototypes (UF5), this track ensures a professional standard in visual design and information architecture.

Bienvenido al **Hub de Fundamentos HTML de 1SMX**. Este directorio orquesta la primera inmersión en el mundo del Desarrollo Web.
