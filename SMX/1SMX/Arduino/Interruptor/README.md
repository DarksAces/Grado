# 🕹️ SwitchLogic: Arduino Digital Input Orchestration
# 🕹️ SwitchLogic: Orquestación de Entrada Digital con Arduino

## 📋 Description | Descripción

A foundational **Arduino (Micro-controller)** laboratory developed in **1SMX** focusing on the programmatic capture of physical button states. **SwitchLogic** implements an interactive system where a momentary switch (button) is used to toggle hardware states, mastering the use of `digitalRead()`, internal pull-up/pull-down resistors, and basic debouncing logic to ensure reliable user interaction.

Un laboratorio fundamental de **Arduino** desarrollado en **1SMX** centrado en la captura programática de estados de botones físicos. **SwitchLogic** implementa un sistema interactivo donde un interruptor se usa para conmutar estados de hardware.

---

## ✨ Key Features | Características Clave

- **Dynamic State Capture:** High-precision monitoring of digital pins using polling logic. | *Captura de Estado Dinámica: Monitoreo de pines digitales.*
- **Interactive Feedback:** Real-time hardware response (LED/Symbol) driven by physical user input. | *Feedback Interactivo: Respuesta de hardware en tiempo real.*
- **Pull-up Resistor Mastery:** Implementation of stable input circuits to mitigate floating pin interference. | *Dominio de Resistencias Pull-up.*
