# 🌡️ BioLogic: Orquestación de Feedback Ambiental (Micro-README)

## 📋 Description | Descripción

This directory contains the orchestrated implementation for linking **DHT environmental sensor** data with **Button/LED hardware feedback**. It masters the logic for triggering visual alerts based on temperature/humidity thresholds.

Este directorio contiene la implementación orquestada para enlazar datos del sensor ambiental **DHT** con feedback de **Botón/LED**.

---

## 🚀 How to Run | Cómo Ejecutar

Open the `.ino` sketch in the **Arduino IDE** and upload to your board. | *Abre el sketch en la **Arduino IDE** y súbelo a tu placa.*
