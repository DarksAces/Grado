## 📋 Description | Descripción

This directory contains the final, high-impact implementation of the **BioSense** curriculum. It orchestrates the concurrent usage of **DHT sensors**, **Buttons**, and **LED feedback engines** into a single, unified industrial monitoring prototype.

Este directorio contiene la implementación final de alto impacto del currículo de **BioSense**. Orquesta el uso concurrente de sensores DHT y motores de feedback.
