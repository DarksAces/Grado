# 🤖 Arduino & IoT: Hardware Interfacing Lab (SMX)
# 🤖 Arduino e IoT: Laboratorio de Interfaz de Hardware (SMX)

## 📋 Overview | Resumen de Proyecto

A comprehensive collection of **Embedded Systems** and **IoT** projects developed during the **1st year of SMX**. This module explores the synergy between C-based firmware and physical components, featuring everything from basic sensor integration (DHT) to complex device control (Motors/IR) and interactive hardware games.

Una colección completa de proyectos de **Sistemas Embebidos** e **IoT** desarrollados durante el **1er año de SMX**. Este módulo explora la sinergia entre el firmware basado en C y los componentes físicos, incluyendo desde integración básica de sensores (DHT) hasta control complejo de dispositivos y juegos de hardware interactivos.

---

## ✨ Key Features | Características Clave

- **Sensor Integration:** Advanced use of **DHT11/22** for environmental monitoring and **Touch Sensors** for user input. | *Integración de Sensores: Uso avanzado de DHT para monitoreo ambiental.*
- **Actuators & Motors:** Precise control of **DC/Servo Motors** using potentiometers and logical triggers. | *Actuadores y Motores: Control preciso de motores usando potenciómetros.*
- **Visual Feedback:** Implementation of **LCD Displays** and **7-Segment Displays** for real-time data visualization. | *Feedback Visual: Implementación de pantallas LCD y Displays de 7 segmentos.*
- **Remote Control:** Integration of **IR Receivers** to command hardware actions via infrared signals. | *Control Remoto: Integración de receptores IR para comandos inalámbricos.*
- **Interactive Hardware Games:** Creative logic implementation in projects like "Adivina el número" using physical components. | *Juegos de Hardware Interactivos: Implementación de lógica creativa en componentes físicos.*

---

## 🛠️ Tech Stack | Tecnologías

- **Environment:** Arduino IDE.
- **Language:** C++ (Arduino dialect).
- **Core Components:** Arduino UNO/Nano, DHT sensors, Potentiometers, IR Receivers, LCD Displays.

---

## 📂 Included Modules | Módulos Incluidos

- **`/Semaforo/`**: Logic for traffic light simulation. | *Simulación de semáforo.*
- **`/Pantalla y DHT/`**: Environmental station with LCD output. | *Estación ambiental con salida LCD.*
- **`/Potenciometro y motor/`**: Hardware speed/direction control. | *Control de hardware.*
- **`/Juego/`**: Interactive hardware-software logic loops. | *Bucle de lógica interactiva.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open any `.ino` file in the **Arduino IDE**. | *Abre cualquier archivo `.ino` en el IDE de Arduino.*
2.  Connect your Arduino board and configure the correct COM port. | *Conecta tu placa Arduino y configura el puerto COM.*
3.  Upload the code and monitor the outputs via the **Serial Monitor** or physical components. | *Sube el código y monitorea las salidas.*
