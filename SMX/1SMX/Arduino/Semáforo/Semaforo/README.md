# 🚦 LightLogic: Núcleo de Implementación del Sketch (Micro-README)

## 📋 Description | Descripción

This directory contains the primary `.ino` sketch for the **LightLogic** traffic signal orchestration. It defines the specific pin-mapping and iterative timing logic for the LED sequencer.

Este directorio contiene el sketch `.ino` primario para la orquestación de semáforo **LightLogic**. Define el mapeo de pines y los tiempos iterativos para el secuenciador LED.

---

## 🚀 How to Run | Cómo Ejecutar
