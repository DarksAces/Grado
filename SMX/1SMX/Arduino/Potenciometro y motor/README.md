# ⚙️ MotorLogic: Control de Actuadores y I/O Analógico con Arduino

## 📋 Description | Descripción

A specialized **Arduino engineering** laboratory developed in **1SMX** focusing on the orchestration of **Analog Input** and **Mechanical Actuators**. **MotorLogic** implements a dual-control system where a **Potentiometer** is used to capture variable user input, which is then dynamically translated into motor speed or rotational patterns. This project masters the integration of **PWM (Pulse Width Modulation)** and high-precision mapping of analog values for industrial robotics foundations.

Un laboratorio especializado de **ingeniería con Arduino** desarrollado en **1SMX** centrado en la orquestación de **Entrada Analógica** y **Actuadores Mecánicos**. **MotorLogic** implementa un sistema de control dual donde un **Potenciómetro** se usa para capturar la entrada del usuario.

---

## ✨ Key Features | Características Clave

- **PWM Actuator Orchestration:** Mastering the usage of `analogWrite()` for variable speed control and high-performance torque management. | *Orquestación de Actuadores PWM: Dominio de analogWrite.*
- **Analog Input Mapping:** High-precision translation of 10-bit potentiometer data (0-1023) into 8-bit PWM signals (0-255). | *Mapeo de Entrada Analógica: Traducción de datos de 10 bits.*
- **Real-time Mechanical Feedback:** Dynamic hardware response loop for immediate actuator state updates. | *Feedback Mecánico en Tiempo Real.*
- **Resource Protection:** Integration of resistors and driver-aware logic to ensure hardware longevity. | *Protección de Recursos.*
