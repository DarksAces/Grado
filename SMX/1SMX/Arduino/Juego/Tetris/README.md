## 📋 Description | Descripción

This directory contains the primary `.ino` sketch for the **TetriCore** retro game. It orchestrates the high-performance rendering logic and real-time input capture for the Arduino hardware.

Este directorio contiene el sketch `.ino` primario para el juego retro **TetriCore**. Orquesta la lógica de renderizado de alto rendimiento y la captura de entradas en tiempo real.
