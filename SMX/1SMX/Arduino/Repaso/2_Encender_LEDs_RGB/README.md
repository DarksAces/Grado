# 🎨 RGBCraft: Orquestación Hardware Cromática (Micro-README)

## 📋 Description | Descripción

This directory focuses on the orchestration of **RGB LED** modules using Arduino. It masters the use of multi-pin digital outputs to synthesize different colors and transitions, ensuring a robust foundational understanding of PWM (Pulse Width Modulation) and color theory in physical systems.

Este directorio se centra en la orquestación de módulos **LED RGB** usando Arduino. Domina el uso de salidas digitales multi-pin.

---

## 🚀 How to Run | Cómo Ejecutar

Open the `.ino` sketch in the **Arduino IDE** and upload to your board. | *Abre el sketch en la **Arduino IDE** y súbelo a tu placa.*
