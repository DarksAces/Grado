## 📋 Overview | Visión General

Welcome to the **Foundational Review (Repaso) Hub**. This directory manages the mastery of basic hardware orchestration and algorithmic thinking using **Arduino**. The curriculum is structured to build a robust mindset in **Procedural Electronics**, moving from basic LED sequences to advanced multi-segment synchronization, variable orchestration, and physical interrupt handling (Buttons).

Bienvenido al **Hub de Repaso Fundamental**. Este directorio gestiona el dominio de la orquestación básica de hardware y el pensamiento algorítmico usando **Arduino**.
