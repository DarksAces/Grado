# 🛠️ LoopSync: Modulación Fundamental de LED (Micro-README)

## 📋 Description | Descripción

This directory contains the foundational **Arduino Hello World** equivalent. It orchestrates the basic use of `digitalWrite()` and `delay()` to modulate a single LED state in a recurring 1-second loop, mastering the principles of hardware synchronization.

Este directorio contiene el equivalente a **Hello World** en Arduino. Orquesta el uso básico de `digitalWrite()` y `delay()`.

---

## 🚀 How to Run | Cómo Ejecutar

Open the `.ino` sketch in the **Arduino IDE** and upload to your board. | *Abre el sketch en la **Arduino IDE** y súbelo a tu placa.*
