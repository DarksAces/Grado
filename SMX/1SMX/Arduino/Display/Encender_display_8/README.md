# 🔢 SegmentCheck: Initial Display Verification (Micro-README)
# 🔢 SegmentCheck: Verificación Inicial del Display (Micro-README)

## 📋 Description | Descripción

This directory contains the foundational hardware test for the **7-Segment Display** curriculum. It orchestrates the activation of all 8 segments (including the decimal point) to ensure correct wiring and pin configuration before implementing counter logic.

Este directorio contiene el test de hardware fundamental para el currículo de **Display de 7 Segmentos**. Orquesta la activación de todos los hilos.

---

## 🚀 How to Run | Cómo Ejecutar

Open the `.ino` sketch in the **Arduino IDE** and upload to your board. | *Abre el sketch en la **Arduino IDE** y súbelo a tu placa.*
