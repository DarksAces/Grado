# 🔢 DigitCounter: Sequential Numeric Orchestration (Micro-README)
# 🔢 DigitCounter: Orquestación Numérica Secuencial (Micro-README)

## 📋 Description | Descripción

This directory contains the primary implementation of a sequential **7-Segment Counter** (0-9) using Arduino. It masters the use of bitmask arrays to map decimal integers to hardware segment pins.

Este directorio contiene la implementación primaria de un **Contador de 7 Segmentos** secuencial (0-9) usando Arduino.

---

## 🚀 How to Run | Cómo Ejecutar

Open the `.ino` sketch in the **Arduino IDE** and upload to your board. | *Abre el sketch en la **Arduino IDE** y súbelo a tu placa.*
