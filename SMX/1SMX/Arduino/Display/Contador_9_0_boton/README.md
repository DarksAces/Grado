# 🔢 ButtonDigit: Interactive Counter Orchestration (Micro-README)
# 🔢 ButtonDigit: Orquestación de Contador Interactivo (Micro-README)

## 📋 Description | Descripción

This directory contains the primary implementation of an interactive **7-Segment Counter** using Arduino. It masters the integration of digital button inputs with segment mapping logic to achieve real-time, user-driven numeric increments.

Este directorio contiene la implementación primaria de un **Contador de 7 Segmentos** interactivo. Domina la integración de entradas de botón con lógica de mapeo.

---

## 🚀 How to Run | Cómo Ejecutar

Open the `.ino` sketch in the **Arduino IDE** and upload to your board. | *Abre el sketch en la **Arduino IDE** y súbelo a tu placa.*
