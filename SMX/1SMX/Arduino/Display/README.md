# 🔢 DigitMaster: Orquestación de Display de 7 Segmentos con Arduino

## 📋 Description | Descripción

A specialized **Arduino hardware** laboratory developed in **1SMX** focused on the low-level orchestration of multi-segment LED displays. **DigitMaster** implements various counters (Up/Down) and interactive digital representations, mastering the usage of bitwise logic and synchronized digital outputs to render numeric data on 7-segment hardware.

Un laboratorio especializado de **hardware con Arduino** desarrollado en **1SMX** centrado en la orquestación de bajo nivel de sistemas de displays LED de múltiples segmentos. **DigitMaster** implementa varios contadores interactivos.

---

## ✨ Key Features | Características Clave

- **Multi-Segment Control:** High-precision management of 7-segment pin mapping to render digits from 0-9. | *Control Multi-Segmento: Gestión de pines para renderizar dígitos.*
- **Interactive Counters:** Implementation of button-driven incremental logic and automated countdown sequences. | *Contadores Interactivos: Lógica incremental.*
- **Logical Mapping:** Specialized lookup functions to translate decimal integers into binary segment patterns. | *Mapeo Lógico: Traducción de enteros a patrones binarios.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** C++ (Arduino).
- **Hardware:** 7-Segment Common Cathode/Anode Display.
- **Concepts:** Pin Mapping, Bitwise Logic, Synchronous Output.
