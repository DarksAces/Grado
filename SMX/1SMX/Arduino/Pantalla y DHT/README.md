# 📟 DisplaySync: Orquestación de Pantalla LCD y Sensores con Arduino

## 📋 Description | Descripción

A professional **Arduino (Micro-controller)** laboratory developed in **1SMX** focusing on the orchestration of high-density hardware outputs. **DisplaySync** implements a multi-module system to render environmental data from **DHT (Temperature/Humidity)** sensors onto **LiquidCrystal (LCD)** displays. This project masters the integration of I2C/Parallel communication protocols, real-time sensor polling, and synchronized text rendering for industrial monitoring systems.

Un laboratorio profesional de **Arduino** desarrollado en **1SMX** centrado en la orquestación de salidas de hardware de alta densidad. **DisplaySync** implementa un sistema multi-módulo para renderizar datos ambientales en pantallas LCD.

---

## ✨ Key Features | Características Clave

- **I2C/Parallel LCD Orchestration:** Mastery of the `LiquidCrystal` library for high-precision text rendering and display buffering. | *Orquestación LCD I2C/Paralelo: Dominio de la librería LiquidCrystal.*
- **DHT Sensor Integration:** Real-time polling of environmental data (Temperature/Humidity) with specialized error-handling logic. | *Integración de Sensores DHT: Muestreo en tiempo real.*
- **Synchronized UI Loop:** Dynamic refresh cycles to ensure up-to-date environmental metrics are displayed without flickering. | *Bucle UI Sincronizado.*
- **Custom Character support:** Usage of byte-arrays to define specialized 0x pixels for custom indicators. | *Soporte para Caracteres Personalizados.*
