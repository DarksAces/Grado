## 📋 Description | Descripción

A specialized **Python algorithmic laboratory** project developed in **2SMX** focusing on advanced logical branching and data categorization. This directory contains a progressive series of challenges—from standard conditional problems (Leap years, BMI calculation) to geometric validation (Triangles) and complex control flow orchestration using nested `while` loops. This track is designed to master industrial-grade decision engines and high-precision data analysis in Python.
