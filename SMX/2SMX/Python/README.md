## 📋 Description | Visión General

Welcome to the **2SMX Python Hub**. This directory orchestrates the first year of Python immersion, moving from foundational sequential logic to advanced **Tkinter GUI** orchestration and complex algorithmic problem-solving. This curriculum is designed to build a robust programmatic foundation, ensuring proficiency in control structures, function modularization, and user-driven interactive systems.

Bienvenido al **Hub de Python de 2SMX**. Este directorio orquesta el primer año de inmersión en Python, desde la lógica secuencial básica hasta la orquestación avanzada de GUIs.
