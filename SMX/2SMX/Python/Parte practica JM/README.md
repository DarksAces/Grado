# 🐍 Python GUI & Utilities: Tkinter & Practice (SMX)
# 🐍 GUI y Utilidades Python: Tkinter y Práctica (SMX)

## 📋 Overview | Resumen de Proyecto

A collection of **Python GUI** exercises and utility scripts developed during the **2nd year of SMX**. This module explores desktop application development using **Tkinter**, focusing on layout management (`grid`), event handling, and practical tools like custom calculators.

Una colección de ejercicios de **GUI en Python** y scripts de utilidad desarrollados durante el **2º año de SMX**. Este módulo explora el desarrollo de aplicaciones de escritorio usando **Tkinter**, enfocándose en la gestión de diseños (`grid`), manejo de eventos y herramientas prácticas como calculadoras personalizadas.

---

## ✨ Key Features | Características Clave

- **Layout Management:** Advanced use of the `grid()` manager in Tkinter to create structured and responsive desktop interfaces. | *Gestión de Diseños: Uso avanzado del gestor `grid()` en Tkinter para crear interfaces de escritorio estructuradas.*
- **Functional Calculators:** Multiple calculator implementations demonstrating mathematical logic and user interaction. | *Calculadoras Funcionales: Múltiples implementaciones de calculadoras que demuestran lógica matemática e interacción.*
- **Learning Resources:** A dedicated `/Tutoriales/` directory containing step-by-step guides for mastering core Python concepts. | *Recursos de Aprendizaje: Directorio `/Tutoriales/` con guías paso a paso para dominar conceptos de Python.*
- **Component Placement:** specialized scripts (`Situar en pantalla grid.py`) focusing on exact UI positioning and widget alignment. | *Posicionamiento de Componentes: Scripts especializados enfocados en el posicionamiento exacto de la UI y alineación de widgets.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Python 3.x
- **GUI Framework:** Tkinter
- **Concepts:** Event-driven programming, Grid layout, UI Design.

---

## 📂 Project Structure | Estructura del Proyecto

- **`/Calculadoras/`**: Various calculator tools. | *Varias herramientas de calculadora.*
- **`/Tutoriales/`**: Educational code snippets. | *Fragmentos de código educativos.*
- **`Situar en pantalla grid.py`**: Visual guide for Tkinter layout. | *Guía visual para el diseño con Tkinter.*
