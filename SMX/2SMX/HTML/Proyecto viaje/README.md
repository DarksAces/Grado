# ✈️ Wanderlust: Showcase de Destinos y Hub de Viajes (SMX)

## 📋 Description | Descripción

A themed **Web Design** project developed in **2SMX** focusing on destination marketing and tourism information architecture. **Wanderlust** implements a clean, multi-module structure to present diverse travel destinations. This project demonstrates proficiency in semantic HTML5 segmentation, high-density image optimization for tourism content, and thematic CSS orchestration for a professional "travel agency" experience.

Un proyecto de **Diseño Web** temático desarrollado en **2SMX** centrado en el marketing de destinos y la arquitectura de información turística. **Wanderlust** implementa una estructura limpia de múltiples módulos para presentar diversos destinos de viaje.

---

## ✨ Key Features | Características Clave

- **Modular Destination Segments:** Categorized `/HTML/` pages for indvidiual tourist spots, allowing for a structured content flow. | *Segmentos de Destino Modulares: Páginas categorizadas.*
- **Immersive Visual Experience:** Specialized `/Fotos/` directory managed via optimized HTML media orchestration to highlight landscape aesthetics. | *Experiencia Visual Inmersiva: Directorio especializado de fotos.*
- **Custom Tourism-Themed UI:** Professional `/CSS/` layer designed to evoke a sense of adventure and clarity for travelers. | *UI Temática de Turismo: Capa CSS profesional.*
- **Responsive Layout Design:** Adaptive structure focused on high readability and accessible navigation across different screen sizes. | *Diseño de Layout Responsivo: Estructura adaptativa.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** HTML5, CSS3.
- **Concepts:** Information architecture, Tourism branding, Image optimization, Modular web design.

---

## 📂 Project Structure | Estructura del Proyecto

- **`index.html`**: The main travel hub and "Hero" destination logic. | *El hub de viajes principal.*
- **`/HTML/`**: Sub-pages for individual destinations and technical travel details. | *Sub-páginas para destinos.*
- **`/CSS/`**: Visual stylesheets and thematic consistent definitions. | *Hojas de estilo visuales.*
- **`/Fotos/`**: Optimized visual assets for the tourism showcase. | *Activos visuales optimizados.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the `index.html` file in any modern web browser. | *Abre `index.html` en cualquier navegador.*
2.  Navigate through the travel destinations using the integrated menu. | *Navega a través de los destinos.*
3.  Analyze the semantic structure to see how tourism data is professionally segmented. | *Analiza la estructura semántica.*
