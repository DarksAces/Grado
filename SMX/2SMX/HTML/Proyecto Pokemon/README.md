# 🐲 PokéDex: Advanced Themed Web Catalog (SMX)
# 🐲 PokéDex: Catálogo Web Temático Avanzado (SMX)

## 📋 Description | Descripción

A high-impact **themed web project** developed in **2SMX** that focuses on the creation of a professional-grade **Pokémon Catalog**. **PokéDex** utilizes a robust multi-page architecture to categorize and display high-density media assets. This project demonstrates proficiency in semantic HTML5 organization, creative CSS branding, and professional resource management (Images/Layout) to deliver an engaging, interactive data-driven experience.

Un proyecto web **temático** de alto impacto desarrollado en **2SMX** que se centra en la creación de un **Catálogo Pokémon** de grado profesional. **PokéDex** utiliza una arquitectura de múltiples páginas robusta para categorizar y mostrar activos multimedia de alta densidad.

---

## ✨ Key Features | Características Clave

- **Multi-Category Catalog:** Structured `/HTML/` navigation categorized by Pokémon types, ensuring a clean and high-performance UX. | *Catálogo Multi-Categoría: Navegación estructurada por tipos.*
- **Thematic Adaptive Design:** Custom `/CSS/` logic tailored to evoke the iconic aesthetics of the franchise across all pages. | *Diseño Adaptativo Temático: Lógica CSS personalizada.*
- **Social Media Integration:** Specialized `/Fotos/Redes sociales/` module for integrated community linking and branding. | *Integración con Redes Sociales: Módulo especializado.*
- **Rich Asset Orchestration:** High-density `/Fotos/` directory managed via optimized HTML media tags. | *Orquestación de Activos Ricos: Directorio de fotos optimizado.*

## 📂 Project Structure | Estructura del Proyecto

- **`HTML/`**: Primary data pages for individual Pokémon entries and categories. | *Páginas de datos primarios para entradas individuales.*
- **`CSS/`**: Visual stylesheets and thematic consistent definitions. | *Hojas de estilo visuales y definiciones temáticas.*
- **`Fotos/`**: Specialized repository of optimized character and UI assets. | *Repositorio de activos optimizados.*
