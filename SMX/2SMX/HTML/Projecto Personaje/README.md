# 🎭 PersonaWeb: Themed Identity & Typography Showcase (SMX)
# 🎭 PersonaWeb: Showcase de Identidad Temática y Tipografía (SMX)

## 📋 Description | Descripción

A creative **Web Design** project developed in **2SMX** that focuses on thematic identity and advanced typography integration. **PersonaWeb** utilizes custom fonts (`EstilosLetras`) and structured CSS to create a unique presentation centered around a specific character or figure. This project demonstrates mastery in font-face implementation, layout orchestration, and visual storytelling through HTML/CSS.

Un proyecto creativo de **Diseño Web** desarrollado en **2SMX** que se centra en la identidad temática y la integración avanzada de tipografía. **PersonaWeb** utiliza fuentes personalizadas y CSS estructurado para crear una presentación única.

---

## ✨ Key Features | Características Clave

- **Advanced Typography Engine:** Specialized `/EstilosLetras/` module featuring multiple high-impact font formats for thematic immersion. | *Motor de Tipografía Avanzado: Módulo especializado con múltiples formatos de fuente.*
- **Themed Layout Design:** Custom-built CSS Grid/Flexbox architecture designed to highlight character attributes and narrative data. | *Diseño de Layout Temático: Arquitectura CSS diseñada para resaltar atributos.*
- **Cross-Font Compatibility:** Integration of diverse font families (AquaWave, Copyduck, Manga Temple) managed through CSS orchestration. | *Compatibilidad Cross-Font: Integración de diversas familias de fuentes.*
- **Responsive Web Standards:** Semantic HTML5 structure ensuring high readability and clean asset organization. | *Estándares Web Responsivos: Estructura HTML5 semántica.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** HTML5, CSS3.
- **Typography:** Custom Font Hosting / @font-face integration.
- **Design:** Themed UI/UX, Asset management.

## 📂 Project Structure | Estructura del Proyecto

- **`Index.html`**: The primary narrative canvas and structure of the character showcase. | *El lienzo narrativo principal.*
- **`/Css/`**: Directory containing the visual layer and typography orchestrators. | *Directorio con la capa visual.*
- **`/EstilosLetras/`**: Specialized repository of the project's custom font families. | *Repositorio especializado de familias de fuentes.*
