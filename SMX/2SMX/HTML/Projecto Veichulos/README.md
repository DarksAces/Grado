# 🏎️ AutoVantage: Showcase Automotriz Multi-Categoría (SMX)

## 📋 Description | Descripción

A themed **Web Project** developed in **2SMX** that focuses on automotive cataloguing and structured visual storytelling. **AutoVantage** implements a clean, multi-page architecture to showcase different categories of vehicles. This project demonstrates proficiency in semantic HTML5 organization, high-density image management, and thematic CSS styling to create a professional "showroom" experience.

Un proyecto web **Temático** desarrollado en **2SMX** que se centra en la catalogación automotriz y la narrativa visual estructurada. **AutoVantage** implementa una arquitectura limpia de múltiples páginas para mostrar diferentes categorías de vehículos.

---

## ✨ Key Features | Características Clave

- **Multi-Module Page Segments:** Categorized `/Html/` structure for different vehicle types, allowing for high-scalability content. | *Segmentos de Página Multi-Módulo: Estructura categorizada.*
- **High-Density Aesthetic Branding:** Custom `/Css/` rules designed to emphasize high-speed themes and professional automotive aesthetics. | *Branding Estético: Reglas CSS diseñadas para enfatizar temas de alta velocidad.*
- **Rich Media Catalog:** Specialized `/Fotos/` gallery containing optimized visual assets for the automotive showcase. | *Catálogo Multimedia: Galería especializada de fotos.*
- **Responsive Architecture:** Clean layout designed to handle large-format imagery while maintaining readability. | *Arquitectura Responsiva: Layout diseñado para manejar imágenes de gran formato.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** HTML5, CSS3.
- **Concepts:** Content Segmentation, Thematic Branding, Gallery Management, Semantic structures.

---

## 📂 Project Structure | Estructura del Proyecto

- **`Index.html`**: The primary "showroom" entrance and landing logic. | *La entrada principal al showroom.*
- **`/Html/`**: Sub-pages for individual vehicle categories and technical details. | *Sub-páginas para categorías.*
- **`/Css/`**: Visual stylesheets and thematic consistent definitions. | *Hojas de estilo visuales.*
- **`/Fotos/`**: Optimized visual assets for the automotive showcase. | *Activos visuales optimizados.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the `Index.html` file in any modern web browser. | *Abre `Index.html` en cualquier navegador.*
2.  Navigate through the automotive categories using the integrated links. | *Navega a través de las categorías.*
3.  Explore the high-density image galleries to observe the thematic design. | *Explora las galerías de imágenes.*
