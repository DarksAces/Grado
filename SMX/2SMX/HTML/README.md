# 🎨 2SMX Diseño Web Avanzado: Frameworks Responsivos y UI Temática

## 📋 Description | Visión General

Welcome to the **2SMX Web Development Hub**. This directory focuses on the mastery of modern **Frontend Engineering** and the implementation of industrial design standards. From foundational **Bootstrap** laboratories (BootMaster V1-V3) to the creation of premium restaurant experiences like **Jovaggio Cuisine**, this curriculum ensures proficiency in **Mobile-First Design**, multi-page architecture, and high-density media orchestration.

Bienvenido al **Hub de Desarrollo Web de 2SMX**. Este directorio se centra en el dominio de la ingeniería frontend moderna y el diseño industrial.

---

## 📂 Curriculum Modules | Módulos del Currículo

- **[BootMaster Series](Projecto%20Boostrap%201/)**: A systematic 3-stage track for mastering the **Bootstrap** framework, moving from basic grids to advanced interactive SPAs. | *Seguimiento sistemático para dominar Bootstrap.*
- **[Jovaggio Cuisine](Jovaggio/Pagina%20Web%20Final/)**: The flagship final project implementing a premium, multi-page restaurant digital presence. | *Proyecto insignia final de un restaurante premium.*
- **[Thematic Showcases](Projecto%20Veichulos/)**: Advanced laboratories for category-specific web design, including **AutoVantage** (Vehicles) and **Wanderlust** (Travel Hubs). | *Laboratorios avanzados de diseño web temático.*
- **[PersonaWeb](Projecto%20Personaje/)**: Specialized project for advanced typography integration and character-themed UI. | *Proyecto especializado en tipografía y UI temática.*
