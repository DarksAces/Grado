# 🎨 Jovaggio: Final Technical Website (SMX)
# 🎨 Jovaggio: Sitio Web Técnico Final (SMX)

## 📋 Description | Descripción

The capstone web project for the **2nd year of SMX**. This project demonstrates a complete frontend implementation including semantic HTML structure, advanced CSS styling, and interactive JavaScript form handling.

El proyecto web final para el **2º año de SMX**. Este proyecto demuestra una implementación frontend completa que incluye estructura HTML semántica, estilos CSS avanzados y manejo interactivo de formularios con JavaScript.

---

## ✨ Key Features | Características Clave

- **Multi-page Architecture:** Organized into logical sections for a professional UX. | *Arquitectura Multi-página: Organizada en secciones lógicas para una UX profesional.*
- **Interactive Forms:** Uses `formulario.js` for client-side data capture and event handling. | *Formularios Interactivos: Usa `formulario.js` para la captura de datos en el cliente y el manejo de eventos.*
- **Responsive Styling:** Custom CSS layout designed to showcase modern web design principles learned during the degree. | *Estilo Responsivo: Diseño CSS personalizado diseñado para mostrar los principios de diseño web moderno aprendidos durante el grado.*
- **Asset Management:** Clean directory structure separating HTML, CSS, and JS components. | *Gestión de Activos: Estructura de directorios limpia separando componentes HTML, CSS y JS.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** HTML5, CSS3, JavaScript (ES6)
- **Paradigm:** Focused on client-side interactivity and clean UI/UX.

---

## 📂 Project Structure | Estructura del Proyecto

- **`Index.html`**: The main landing page. | *La página de aterrizaje principal.*
- **`/html/`**: Subpages containing detailed technical content. | *Subpáginas que contienen contenido técnico detallado.*
- **`/CSS/`**: Stylesheets for layout and aesthetics. | *Hojas de estilo para el diseño y la estética.*
- **`/Java script/`**: Interactive logic and form validation. | *Lógica interactiva y validación de formularios.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open `Index.html` in any web browser. | *Abre `Index.html` en cualquier navegador web.*
2.  Navigate through the different sections using the menu. | *Navega a través de las diferentes secciones usando el menú.*
3.  Test the contact form in the footer or contact section. | *Prueba el formulario de contacto en el pie de página o sección de contacto.*
