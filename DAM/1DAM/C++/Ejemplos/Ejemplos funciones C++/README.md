# 🧩 C++ Logic Lab: Core Functions & Algorithmic Patterns
# 🧩 C++ Logic Lab: Funciones Core y Patrones Algorítmicos

## 📋 Description | Descripción

A specialized logic laboratory developed in **1DAM** to master **C++ Functional Programming**. It provides a comprehensive exploration of modular code design, parameter passing (by value and reference), and the implementation of fundamental algorithms (sorting, searching, and mathematical puzzles) using native C++ constructs.

Un laboratorio de lógica especializado desarrollado en **1DAM** para dominar la **Programación Funcional en C++**. Proporciona una exploración exhaustiva del diseño de código modular, paso de parámetros (por valor y referencia) e implementación de algoritmos fundamentales usando construcciones nativas de C++.

---

## ✨ Key Features | Características Clave

- **Functional Modularity:** Extensive library of custom functions demonstrating clean code principles and high reuse. | *Modularidad Funcional: Biblioteca extensa de funciones personalizadas que demuestran principios de código limpio.*
- **Pointer & Reference Mastery:** Practical examples of memory management and efficient variable manipulation. | *Maestría en Punteros y Referencias: Ejemplos prácticos de gestión de memoria.*
- **Algorithm Suite:** Implementation of various computational logic patterns, including array processing and mathematical sequences. | *Suite de Algoritmos: Implementación de varios patrones de lógica computacional.*
- **Strict Typing:** Demonstrates C++'s strong type system for error prevention and optimized execution. | *Tipado Estricto: Demuestra el sistema de tipos fuerte de C++ para la prevención de errores.*

---

## 🛠️ Tech Stack | Tecnologías

- **Environment:** Visual Studio (MSVC Toolchain).
- **Language:** C++11 / C++14.
- **Concepts:** Functions (`def`), Overloading, Static Memory management.

---

## 📂 Project Structure | Estructura del Proyecto

- **`Proyecto funciones C++.cpp`**: The primary source file containing all logic implementations and the test orchestrator. | *El archivo fuente principal que contiene todas las implementaciones.*
- **`Proyecto funciones C++.sln`**: Visual Studio solution for immediate deployment. | *Solución de Visual Studio para despliegue inmediato.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the `.sln` file in **Visual Studio**. | *Abre el archivo `.sln` en **Visual Studio**.*
2.  Press **F5** to build and run the main test suite. | *Presiona **F5** para compilar y ejecutar.*
3.  Analyze the console output to see the result of the different algorithmic implementations. | *Analiza la salida de consola para ver los resultados.*
