# ⚔️ 1DAM C++: Currículo de Lógica de Alto Rendimiento y Motores de Juego

## 📋 Overview | Visión General

Welcome to the **1DAM C++ Hub**. This directory contains the low-level logic laboratories specifically designed to master performance-oriented development. From foundational procedural functions to the creation of modular **2D Fighting Games** and graphical immersion with **SFML**, this curriculum bridge the gap between abstract code and machine-efficient simulation.

Bienvenido al **Hub de C++ de 1DAM**. Este directorio contiene los laboratorios de lógica de bajo nivel diseñados para dominar el desarrollo orientado al rendimiento.

---

## 📂 Curriculum Modules | Módulos del Currículo

- **[Desarrollo Juego Pelea](Desarrollo Juego Pelea/)**: The flagship project evolving through 6 versions, moving from monolithic scripts to modular C++ architectures. | *Proyecto insignia que evoluciona a través de 6 versiones.*
- **[Funciones](Funciones/)**: Intensive laboratories for mastering modular programming and algorithm reuse. | *Laboratorios intensivos para dominar la programación modular.*
- **[SFML](SFML/)**: Graphical immersion module focusing on window management and 2D rendering. | *Módulo de inmersión gráfica y renderizado 2D.*
- **[Ejemplos](Ejemplos/)**: A collection of refactoring techniques, exam simulations, and industrial coding patterns. | *Técnicas de refactorización y patrones industriales.*
