# 🥊 CombatEngine: Text-Based Fighting Evolution (1DAM)
# 🥊 CombatEngine: Evolución de Juego de Pelea (1DAM)

## 📋 Description | Descripción

A systematic evolution of a **Text-Based Fighting Game** engine developed in **C++** during **1DAM**. This project chronicles the journey of building a game from scratch (V1) to a refined version (V6), exploring core game design concepts such as combat mechanics, turn-based systems, and structural refactoring.

Una evolución sistemática de un motor de **Juego de Pelea por Texto** desarrollado en **C++** durante **1DAM**. Este proyecto narra el proceso de construcción de un juego desde cero (V1) hasta una versión refinada (V6), explorando conceptos de diseño de juegos como mecánicas de combate, sistemas por turnos y refactorización estructural.

---

## ✨ Key Features | Características Clave

- **Iterative Development:** Seven distinct versions (V1-V6 + JuegoC) showcasing incremental improvements in logic and features. | *Desarrollo Iterativo: Siete versiones distintas que muestran mejoras incrementales.*
- **Combat Logic:** Turn-based mechanics including health points (HP), attack damage calculations, and basic AI behaviors. | *Lógica de Combate: Mecánicas por turnos que incluyen puntos de vida (HP) y cálculos de daño.*
- **Systematic Refactoring:** Evolution from procedural logic to more structured and modular code across the versions. | *Refactorización Sistemática: Evolución de lógica procedimental a código más estructurado.*
- **State Management:** Management of player statistics and game flow transitions through console-based interaction. | *Gestión de Estado: Administración de estadísticas del jugador y transiciones del flujo de juego.*

---

## 🛠️ Tech Stack | Tecnologías

- **Environment:** Visual Studio (MSVC).
- **Language:** C++.
- **Concepts:** Game Loops, Nested Conditionals, Logic branching, Iterative Design.

---

## 📂 Project Structure | Estructura del Proyecto

- **`/Juego V1/` to `/Juego V6/`**: The chronological progression of the game engine. | *La progresión cronológica del motor de juego.*
- **`Juego V6.cpp`**: The most advanced and optimized implementation in the series. | *La implementación más avanzada y optimizada de la serie.*
- **`/JuegoC/`**: Alternative implementation experiments. | *Experimentos de implementación alternativos.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Navigate to the `Juego V6` directory. | *Navega al directorio `Juego V6`.*
2.  Open the `.sln` file in **Visual Studio**. | *Abre el archivo `.sln` en **Visual Studio**.*
3.  Build and run the project (Press **F5**). | *Compila y ejecuta el proyecto.*
4.  Follow the console instructions to engage in combat! | *¡Sigue las instrucciones de la consola para entrar en combate!*
