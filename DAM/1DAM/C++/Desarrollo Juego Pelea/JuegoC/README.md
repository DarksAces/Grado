# 🥊 FightMaster: Implementación en C Puro

## 📋 Description | Descripción

A specialized implementation of the **Fighting Game Engine** written in **pure C**. This project serves as a procedural contrast to the C++ version, focusing on low-level memory management, standard I/O efficiency, and monolithic logical structures. It represents a fundamental laboratory in procedural architecture and the foundations of game development without the overhead of high-level object-oriented features.

Una implementación especializada del **Motor de Juego de Pelea** escrita en **C puro**. Este proyecto sirve como un contraste procedimental a la versión en C++, enfocándose en la gestión de memoria de bajo nivel y estructuras lógicas monolíticas.

---

## ✨ Key Features | Características Clave

- **Procedural Logic Design:** Entire game state and combat mechanics implemented using standard C functions and control structures. | *Diseño de Lógica Procedimental: Estado del juego implementado con funciones estándar.*
- **Resource Efficiency:** Minimal memory footprint and high-speed execution using the native C library. | *Eficiencia de Recursos: Mínima huella de memoria.*
- **Core Game Loop:** Robust implementation of the battle sequence, randomized damage logic, and win detection. | *Bucle de Juego Core: Implementación robusta de la secuencia de batalla.*
- **Portable Architecture:** Ready for compilation across multiple C-standard environments using Visual Studio or GCC. | *Arquitectura Portable: Listo para compilar en múltiples entornos.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** C (Standard C).
- **Environment:** Visual Studio 2022 (MSVC).
- **Concepts:** Procedural programming, Data structs, Standard I/O, I/O efficiency.

## 📂 Project Structure | Estructura del Proyecto

- **`JuegoC.sln`**: The orchestration file for the Visual Studio C solution. | *El archivo de orquestación de la solución.*
- **`JuegoC.vcxproj`**: The project definition identifying C-specific compilation flags. | *La definición del proyecto con flags específicos de C.*

## 🚀 How to Run | Cómo Ejecutar

1.  Open the `JuegoC.sln` solution in **Visual Studio**. | *Abre la solución en **Visual Studio**.*
2.  Press **F5** to compile and run the procedural combat engine. | *Presiona **F5** para compilar y ejecutar.*
3.  Compare the execution flow with the object-oriented C++ counterparts. | *Compara el flujo de ejecución con las versiones de C++.*
