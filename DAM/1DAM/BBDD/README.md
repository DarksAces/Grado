## 📋 Overview | Visión General

Welcome to the **1DAM Database Hub**. This directory manages the full cycle of the Relational Database curriculum. It transitions from pure data manipulation using **SQL** (Standard Query Language) to advanced procedural automation and business logic encapsulation using **Oracle PL/SQL**. This hub serves as the technical backbone for any backend system requiring persistent, professional data orchestration.

Bienvenido al **Hub de Bases de Datos de 1DAM**. Este directorio gestiona el ciclo completo del currículo de Bases de Datos Relacionales.

---

## 📂 Curriculum Modules | Módulos del Currículo

- **[SQL](SQL/)**: Foundational scripts for data definition (DDL), manipulation (DML), and complex query orchestration. | *Scripts fundamentales para la definición y manipulación de datos.*
- **[PL/SQL](PL/SQL/)**: Advanced procedural programming curriculum. Includes modules for **Cursors**, **Exceptions**, **Stored Procedures**, and high-performance **Triggers**. | *Currículo de programación procedimental avanzada.*
