# 🗄️ PL/SQL Validator: Advanced Database Logic (1DAM)
# 🗄️ Validador PL/SQL: Lógica de Base de Datos Avanzada (1DAM)

## 📋 Description | Descripción

A specialized database programming project developed in **1DAM** using **Oracle PL/SQL**. This module demonstrates the implementation of complex server-side logic, including automated data validation, constraint enforcement, and the use of anonymous blocks to manage relational data integrity.

Un proyecto de programación de bases de datos especializado desarrollado en **1DAM** usando **Oracle PL/SQL**. Este módulo demuestra la implementación de lógica compleja en el lado del servidor, incluyendo la validación automatizada de datos, cumplimiento de restricciones y el uso de bloques anónimos para gestionar la integridad de datos relacionales.

---

## ✨ Key Features | Características Clave

- **Procedural Database Logic:** Implementation of procedural constructs (loops, conditionals) within a relational SQL environment. | *Lógica Procedimental: Implementación de construcciones procedimentales (bucles, condicionales).*
- **Data Integrity Validation:** Advanced scripts to ensure that input data meets specific business rules before persistence. | *Validación de Integridad: Scripts avanzados para asegurar que los datos cumplen las reglas de negocio.*
- **Oracle SQL Extensions:** Comprehensive use of PL/SQL specific features like specialized exception handling and cursor management. | *Extensiones Oracle SQL: Uso exhaustivo de características específicas de PL/SQL.*
- **Relational Mapping:** Direct interaction with normalized database schemas to perform complex data updates and queries. | *Mapeo Relacional: Interacción directa con esquemas normalizados.*

## 🛠️ Tech Stack | Tecnologías

- **Database System:** Oracle Database.

## 📂 Project Structure | Estructura del Proyecto

## 🚀 How to Run | Cómo Ejecutar

1.  Connect to your **Oracle Database** instance (e.g., using SQL Developer or SQL*Plus). | *Conéctate a tu instancia de Oracle.*
2.  Open the `ValidacionPLSQL.sql` script. | *Abre el script SQL.*
3.  Execute the script to create the necessary schema and run the validation blocks. | *Ejecuta el script para crear el esquema.*
4.  Monitor the `DBMS_OUTPUT` console for real-time validation results. | *Monitorea la salida DBMS_OUTPUT.*
