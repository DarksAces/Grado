# 📅 SQL Appointments: Relational Schema & Validation
# 📅 Citas SQL: Esquema Relacional y Validación

## 📋 Description | Descripción

A comprehensive **SQL** project focused on relational database design and data validation. It implements a management system for appointments, demonstrating complex relationships, indexing strategies, and data integrity constraints in a real-world scenario.

Un proyecto completo de **SQL** enfocado en el diseño de bases de datos relacionales y la validación de datos. Implementa un sistema de gestión de citas, demostrando relaciones complejas, estrategias de indexación y restricciones de integridad de datos en un escenario del mundo real.

---

## ✨ Key Features | Características Clave

- **Relational Modeling:** Complete schema design with Primary Keys, Foreign Keys, and many-to-many relationship resolution. | *Modelado Relacional: Diseño de esquema completo con Claves Primarias, Foráneas y resolución de relaciones muchos-a-muchos.*
- **Data Population:** Includes a wide dataset of sample records for testing query performance and data display. | *Población de Datos: Incluye un amplio conjunto de registros de ejemplo para probar el rendimiento de consultas y visualización.*
- **Advanced Constraints:** Implementation of `UNIQUE`, `NOT NULL`, and `CHECK` constraints to ensure data quality at the engine level. | *Restricciones Avanzadas: Implementación de `UNIQUE`, `NOT NULL` y `CHECK` para asegurar la calidad de los datos a nivel de motor.*
- **Query Ready:** Designed to support complex JOINs and aggregate functions for business reporting. | *Listo para Consultas: Diseñado para soportar JOINs complejos y funciones de agregación.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** SQL (ANSI Standard)
- **Engine Compatability:** MySQL, MariaDB, PostgreSQL.
- **Tools:** SQL Scripts for Schema and Data.

---

## 📂 Project Structure | Estructura del Proyecto

- **`citas.sql`**: The master script containing all DDL (Tables, Constraints) and DML (Insertions) instructions. | *El script maestro que contiene todas las instrucciones DDL y DML.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Connect to your SQL Database Server. | *Conéctate a tu servidor de base de datos SQL.*
2.  Execute the `citas.sql` script to create the environment. | *Ejecuta el script `citas.sql` para crear el entorno.*
3.  Perform test queries to verify relationship integrity. | *Realiza consultas de prueba para verificar la integridad de las relaciones.*
