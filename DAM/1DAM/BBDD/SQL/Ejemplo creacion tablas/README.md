# 🐉 Pokémon Database: SQL Schema Example
# 🐉 Base de Datos Pokémon: Ejemplo de Esquema SQL

## 📋 Description | Descripción

A practical example of **SQL Data Definition Language (DDL)** and **Data Manipulation Language (DML)**. This script demonstrates the creation of a relational schema for a Pokémon system, including tables, relationships, and sample data insertions.

Un ejemplo práctico de **Lenguaje de Definición de Datos (DDL)** y **Lenguaje de Manipulación de Datos (DML)** en SQL. Este script demuestra la creación de un esquema relacional para un sistema Pokémon, incluyendo tablas, relaciones e inserciones de datos de ejemplo.

- **Data Integrity:** Implementation of Primary Keys and Foreign Keys to maintain referential integrity. | *Integridad de Datos: Implementación de Claves Primarias y Claves Foráneas para mantener la integridad referencial.*

- **Clean Naming Conventions:** Professional SQL formatting for easy reading and maintenance. | *Convenciones de Nomenclatura Limpias: Formateo SQL profesional para una fácil lectura y mantenimiento.*
