# 🗄️ SQL Engineering: Schema Design & Data Manipulation (1DAM)
# 🗄️ Ingeniería SQL: Diseño de Esquemas y Manipulación (1DAM)

## 📋 Overview | Resumen de Proyecto

A foundational database module from **1DAM** focusing on **Relational Database Management Systems (RDBMS)**. This repository section contains a progression of SQL scripts covering everything from DDL (Data Definition Language) for complex schema creation to advanced DML (Data Manipulation Language) for laboratory exercises and validation tasks.

Un módulo fundamental de bases de datos de **1DAM** enfocado en **Sistemas de Gestión de Bases de Datos Relacionales (RDBMS)**. Esta sección contiene una progresión de scripts SQL que cubren desde DDL para la creación de esquemas complejos hasta DML avanzado para ejercicios de laboratorio.

---

## ✨ Key Features | Características Clave

- **Schema Architecture:** Real-world examples of table creation (`Ejemplo creacion tablas`) including primary keys, foreign keys, and integrity constraints. | *Arquitectura de Esquemas: Ejemplos reales de creación de tablas con claves y restricciones.*
- **SQL Laboratory Suite:** A collection of iterative exercises (`lab_02_xx.sql`) focusing on precise data retrieval and filtered queries. | *Suite de Laboratorio SQL: Colección de ejercicios de consulta de datos.*
- **Validation Protocols:** Advanced scripts designed to verify database states and ensure relational consistency. | *Protocolos de Validación: Scripts avanzados para verificar el estado de la base de datos.*
- **Constraint Management:** Focus on enforcing data types, nullability, and specialized database-level rules. | *Gestión de Restricciones: Enfoque en tipos de datos y reglas de integridad.*

---

## 🛠️ Tech Stack | Tecnologías

- **Database System:** Oracle / MySQL (MariaDB).
- **Language:** SQL (Standard + Dialects).
- **Core Concepts:** DDL, DML, JOINS, Subqueries, Relational Integrity.

## 📂 Project Structure | Estructura del Proyecto

- **`/Ejercicio validacion/`**: Specialized tasks for checking data correctness. | *Tareas especializadas para verificar la corrección de datos.*
