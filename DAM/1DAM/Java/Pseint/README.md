# 🧩 PseudoCode: Algorithmic Foundations (Pseint)
# 🧩 PseudoCódigo: Fundamentos Algorítmicos (Pseint)

## 📋 Overview | Resumen de Proyecto

The absolute point of entry into the world of **Programming Logic**. This module contains a collection of `.psc` files developed using the **Pseint** tool during the beginning of **1DAM**. It focuses on the translation of human thought into structured algorithmic flowcharts and pseudo-code, mastering variables, conditionals, and logical operators before moving to high-level languages like Java.

El punto de entrada absoluto al mundo de la **Lógica de Programación**. Este módulo contiene una colección de archivos `.psc` desarrollados con la herramienta **Pseint** al inicio de **1DAM**. Se centra en la traducción del pensamiento humano a diagramas de flujo y pseudocódigo estructurado.

---

## ✨ Key Features | Características Clave

- **Visual Logic Mapping:** Transitioning from natural language to structured procedural blocks. | *Mapeo Lógico Visual: Transición de lenguaje natural a bloques procedimentales.*
- **Core Comparisons:** Implementation of classic "Greater/Lesser than" algorithms applied to multiple datasets. | *Comparaciones Core: Implementación de algoritmos clásicos de mayor/menor.*
- **Mathematical Foundations:** Basic arithmetic operations and sequence calculations represented in Spanish-based pseudo-code. | *Fundamentos Matemáticos: Operaciones aritméticas básicas.*
- **Flow Control Mastery:** Early adoption of `Si-Entonces` (If-Then) and looping constructs. | *Maestría en Control de Flujo: Adopción temprana de estructuras condicionales.*

---

## 🛠️ Tech Stack | Tecnologías

- **Tool:** Pseint (Algorithmic Interpreter).
- **Language:** Spanish-based pseudo-code.
- **Concepts:** Algorithms, Variables, Logic gates, Sequential execution.

---

## 📂 Included Exercises | Ejercicios Incluidos

- **`A mayor B.psc`**: Fundamental binary comparison. | *Comparación binaria fundamental.*
- **`Mayor 4 numeros.psc`**: Multi-layered conditional nesting. | *Anidamiento condicional de múltiples capas.*
- **`Suma 4.psc`**: Basic accumulation and input logic. | *Lógica básica de acumulación.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Download and install **Pseint**. | *Descarga e instala **Pseint**.*
2.  Open any `.psc` file from the directory. | *Abre cualquier archivo `.psc`.*
3.  Click the "Play" (Run) button to execute the logic in the Pseint console. | *Haz clic en el botón "Reproducir" para ejecutar la lógica.*
4.  Use the "Step by Step" mode to visualize the execution flow. | *Usa el modo "Paso a paso" para visualizar el flujo.*
