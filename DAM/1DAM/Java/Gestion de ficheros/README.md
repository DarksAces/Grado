# 📁 PersistenceEngine: Java File Management & Data Orchestration
# 📁 PersistenceEngine: Gestión de Ficheros y Orquestación de Datos en Java

## 📋 Description | Descripción

A specialized **Backend Persistence** laboratory developed in **1DAM** focused on the orchestration of the physical data layer. **PersistenceEngine** implements a sophisticated **MVC (Model-View-Controller)** pattern to manage data persistence using standard Java I/O libraries. This project masters the usage of `File`, `BufferedReaders`, and `PrintWriter` to ensure secure, high-performance data storage and retrieval in a professional Java ecosystem.

Un laboratorio especializado de **Persistencia Backend** desarrollado en **1DAM** centrado en la orquestación de la capa de datos física. **PersistenceEngine** implementa un patrón **MVC** sofisticado para gestionar la persistencia de datos usando librerías I/O estándar de Java.

---

## ✨ Key Features | Características Clave

- **MVC Structural Integrity:** Clean separation between the `model` (data logic) and `view` (user interaction) for professional software architecture. | *Integridad Estructural MVC: Separación limpia entre lógica de datos y vista.*
- **High-Performance I/O:** Usage of buffered streams to ensure efficient handled of large character-based data files. | *I/O de Alto Rendimiento: Uso de streams con buffer.*
- **CRUD File Orchestration:** Complete implementation of Create, Read, Update, and Delete operations directly onto the filesystem. | *Orquestación CRUD en Ficheros.*
- **Error Mitigation:** Robust Exception Handling logic to ensure system stability during file access. | *Mitigación de Errores: Gestión robusta de excepciones.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Java 8+.
- **Protocol:** Java Standard I/O (java.io).
- **Concepts:** MVC Pattern, File Persistence, Stream Orchestration, Data integrity.

## 📂 Project Structure | Estructura del Proyecto

- **`src/model/`**: The core logical repository for data entities and file-system interaction. | *El repositorio lógico core para entidades e interacción.*
- **`src/view/`**: Interactive user interface layer for terminal-based data management. | *Capa de interfaz interactiva.*
