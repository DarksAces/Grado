# 🧪 TestForge: Laboratorio de Pruebas Unitarias y Calidad en Java

## 📋 Description | Descripción

A professional **Quality Assurance (QA)** laboratory developed in **1DAM** focusing on the foundational principles of automated software validation. **TestForge** masters the usage of **JUnit 5** to ensure code reliability and predictable performance through the implementation of isolated unit tests. This project covers the orchestration of test suites, the handling of edge-case validations, and the transition from manual debugging to industrial-grade automated verification.

Un laboratorio profesional de **Aseguramiento de Calidad (QA)** desarrollado en **1DAM** centrado en los principios fundamentales de la validación automatizada de software. **TestForge** domina el uso de **JUnit 5** para garantizar la fiabilidad del código.

---

## ✨ Key Features | Características Clave

- **JUnit 5 Integration:** High-precision implementation of unit tests for core logical components. | *Integración de JUnit 5: Implementación de pruebas unitarias.*
- **Edge-Case Validation:** Specialized laboratories for identifying and mitigating boundary-value vulnerabilities. | *Validación de Casos Borde: Identificación de vulnerabilidades.*
- **Modular Test Structure:** Clean separation between `main` logic and `test` suites for professional project architecture. | *Estructura de Pruebas Modular: Separación limpia entre lógica y pruebas.*
- **Performance Benchmarking:** Basic techniques for ensuring logical efficiency through repeated test batches. | *Benchmark de Rendimiento.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Java 11+.
- **Testing Framework:** JUnit 5.
- **Concepts:** Unit Testing, TDD foundations, Code Coverage, Assertions.

---

## 📂 Project Structure | Estructura del Proyecto

- **`src/main/`**: The primary logical repository for the project code. | *El repositorio lógico primario.*
- **`src/test/`**: Specialized suite of JUnit tests for automated validation. | *Suite especializada de pruebas JUnit.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the project in your Java IDE (IntelliJ / NetBeans). | *Abre el proyecto en tu IDE.*
2.  Enable the **JUnit** library in your project settings. | *Activa la librería JUnit.*
3.  Right-click the `test` directory and select **"Run Tests"**. | *Ejecuta las pruebas.*
4.  Observe the green/red status reports for each logical assertion. | *Observa los informes de estado.*
