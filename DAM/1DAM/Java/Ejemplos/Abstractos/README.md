# 🎭 PolyDrive: Laboratorio de Abstracción y Polimorfismo en Java

## 📋 Description | Descripción

A specialized **Advanced Java (1DAM)** laboratory focused on the industrial application of **Abstraction** and **Polymorphism**. **PolyDrive** implements a sophisticated vehicle hierarchy where the base `Vehicle` class defines abstract behaviors, which are then concreteley implemented by specialized subclasses (`Car`, `Motorcicle`, `Truk`). This project demonstrates the power of architectural contracts and dynamic method binding in the Java ecosystem.

Un laboratorio especializado de **Java Avanzado (1DAM)** centrado en la aplicación industrial de la **Abstracción** y el **Polimorfismo**. **PolyDrive** implementa una jerarquía de vehículos sofisticada donde la clase base `Vehicle` define comportamientos abstractos.

---

## ✨ Key Features | Características Clave

- **Abstract Architecture Design:** Implementation of pure abstract classes to define behavioral templates for modular development. | *Diseño de Arquitectura Abstracta: Implementación de clases abstractas puras.*
- **Dynamic Polymorphism:** Creation of polymorphic collections capable of handling diverse subclasses through a unified interface. | *Polimorfismo Dinámico: Creación de colecciones polimórficas.*
- **Advanced Enumeration:** Usage of `ColorEnum` and `MotorEnum` for high-precision state management and data integrity. | *Enumeraciones Avanzadas: Uso de ColorEnum y MotorEnum.*
- **Structural Inheritance:** Deep-dive into hierarchies (`Car`, `Motorcicle`, `Truk`) to master code reuse and specialization. | *Herencia Estructural: Profundización en jerarquías.*

## 📂 Project Structure | Estructura del Proyecto

- **`src/model/`**: The core logical repository for the abstract hierarchy and data enums. | *El repositorio lógico core para la jerarquía abstracta.*
- **`Vehicle.java`**: The primary abstract contract for all project entities. | *El contrato abstracto principal.*
- **`Car.java / Truk.java / Motorcicle.java`**: Specialized polymorphic implementations. | *Implementaciones polimórficas especializadas.*
