# 🚀 SpringForge: Laboratorio de Arquitectura Spring Boot Industrial

## 📋 Description | Descripción

A professional **Spring Boot** laboratory developed in **1DAM** using **IntelliJ IDEA** to master modern Java backend architectures. **SpringForge** implements a complete **MVC (Model-View-Controller)** pattern, featuring high-performance orchestration between Controllers, Services, and Repositories. This project serves as a cornerstone for cloud-native development, mastering dependency injection, RESTful API design, and DTO (Data Transfer Object) patterns.

Un laboratorio profesional de **Spring Boot** desarrollado en **1DAM** usando **IntelliJ IDEA** para dominar las arquitecturas backend modernas de Java. **SpringForge** implementa el patrón **MVC** completo, contando con una orquestación de alto rendimiento entre Controladores, Servicios y Repositorios.

---

## ✨ Key Features | Características Clave

- **MVC Structural Design:** Clean separation of concerns through specialized `controller`, `service`, and `repository` modules. | *Diseño Estructural MVC: Separación limpia de responsabilidades.*
- **RESTful API Infrastructure:** Implementation of robust endpoints using Spring Web annotations for high-performance communication. | *Infraestructura API RESTful: Implementación de endpoints robustos.*
- **DTO Strategy:** Specialized `dto` layer to ensure secure and efficient data exchange between system layers. | *Estrategia DTO: Capa especializada para el intercambio seguro de datos.*
- **Spring Lifecycle Management:** Mastery of the Spring Boot application lifecycle and automated bean orchestration. | *Gestión del Ciclo de Vida Spring.*

---

## 🛠️ Tech Stack | Tecnologías

- **Framework:** Spring Boot 3.x.
- **Language:** Java 17+.
- **Build Tool:** Maven / Gradle.
- **Concepts:** Dependency Injection (DI), MVC Pattern, RESTful Services, Data persistence.

---

## 📂 Project Structure | Estructura del Proyecto

- **`demo-DGB/src/main/java/com/example/demo_DGB/`**: The root of the application logic. | *La raíz de la lógica de la aplicación.*
- **`controller/`**: RESTful entry points and request handling. | *Puntos de entrada RESTful.*
- **`service/`**: Core business logic and process orchestration. | *Lógica de negocio core.*
- **`model/`**: Dynamic data entities and domain definitions. | *Entidades de datos dinámicos.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the project in **IntelliJ IDEA**. | *Abre el proyecto en **IntelliJ IDEA**.*
2.  Enable **Annotation Processing** in your IDE settings. | *Activa el Procesamiento de Anotaciones.*
3.  Run the `DemoDgbApplication.java` class. | *Ejecuta la clase principal.*
4.  Interact with the REST endpoints via Postman or your browser. | *Interactúa con los endpoints REST.*
