# ☕ Java logic: Algorithmic Fundamentals (Tema 2)
# ☕ Lógica Java: Fundamentos Algorítmicos (Tema 2)

## 📋 Description | Descripción

A core logic exercise developed in **1DAM** focusing on the foundational pillars of **Java Programming**. This project demonstrates the implementation of efficient control structures, data input validation, and early algorithmic problem-solving using native language constructs.

Un ejercicio de lógica central desarrollado en **1DAM** enfocado en los pilares fundamentales de la **Programación en Java**. Este proyecto demuestra la implementación de estructuras de control eficientes, validación de entrada de datos y resolución de problemas algorítmicos.

---

## ✨ Key Features | Características Clave

- **Control Flow Engineering:** Specialized use of loops and switch-case structures to manage complex program states. | *Ingeniería de Flujo de Control: Uso especializado de bucles y estructuras switch-case.*
- **Native User Interaction:** Robust input handling using `Scanner` and error-prevention logic. | *Interacción de Usuario Nativa: Manejo robusto de entradas usando `Scanner`.*
- **Algorithm Optimization:** Focus on clean, readable code that implements efficient logic for data processing. | *Optimización de Algoritmos: Enfoque en código limpio y legible.*
- **Problem Solving:** Implementation of specific computational challenges assigned during the Tema 2 module. | *Resolución de Problemas: Implementación de desafíos computacionales específicos.*

- **Language:** Java 8+.
