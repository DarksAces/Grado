# ☕ Java Foundation: Advanced Procedural Logic (Tema 2)
# ☕ Java Foundation: Lógica Procedimental Avanzada (Tema 2)

## 📋 Description | Descripción

A milestone project developed during **1DAM (Tema 2)** that focuses on mastering complex control flows and data manipulation in **Java**. This practice integrates nested loops, advanced conditional branching, and early state management techniques to solve multi-step algorithmic challenges.

Un proyecto importante desarrollado durante **1DAM (Tema 2)** que se centra en dominar los flujos de control complejos y la manipulación de datos en **Java**. Esta práctica integra bucles anidados, ramificaciones condicionales avanzadas y técnicas tempranas de gestión de estado para resolver desafíos algorítmicos.

---

## ✨ Key Features | Características Clave

- **Complex Logic Branching:** Exhaustive implementation of `switch` and nested `if-else` structures to handle multiple user input scenarios. | *Ramificaciones de Lógica Compleja: Implementación exhaustiva de estructuras de control.*
- **Array Processing:** Foundational techniques for managing fixed-size data collections and basic search algorithms. | *Procesamiento de Arreglos: Técnicas fundamentales para gestionar colecciones de datos.*
- **Input Sanitization:** Native Java logic to verify user entries and prevent runtime errors during interactive sessions. | *Sanitización de Entrada: Lógica nativa de Java para verificar las entradas del usuario.*
- **Performance Optimization:** Focus on algorithmic efficiency even within procedural paradigms. | *Optimización de Rendimiento: Enfoque en la eficiencia algorítmica.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Java 8+.
- **Core Concepts:** Procedural programming, Data validation, Control structures.
- **Environment:** Standard JDK.

---

## 📂 Project Structure | Estructura del Proyecto

- **`Practica09.java`**: The complete source file containing the main algorithmic logic and interactive loop. | *El archivo fuente completo que contiene la lógica algorítmica.*
- **`Practica09.sln` / Build scripts**: Integration with standard Java build systems. | *Integración con sistemas de compilación.*

## 🚀 How to Run | Cómo Ejecutar

1.  Compile the source code: `javac Practica09.java`. | *Compila el código fuente.*
2.  Run the application: `java Practica09`. | *Ejecuta la aplicación.*
3.  Interact with the console-based engine following the on-screen instructions. | *Interactúa con el motor basado en consola.*
