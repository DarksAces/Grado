# 📋 Java M3-UF2: Modular Logic & Data Validation Practice
# 📋 Java M3-UF2: Práctica de Lógica Modular y Validación de Datos

## 📋 Description | Descripción

A comprehensive **1DAM** practice project focusing on modular programming in **Java**. This module evaluates the ability to separate business logic from user interfaces, implementing robust data validation patterns (using Regex and custom logic) for complex user profiles.

Un proyecto de práctica integral de **1DAM** enfocado en la programación modular en **Java**. Este módulo evalúa la capacidad de separar la lógica de negocio de las interfaces de usuario, implementando patrones robustos de validación de datos (usando Regex y lógica personalizada).

---

## ✨ Key Features | Características Clave

- **Modular Architecture:** Clean separation between the domain model (`model.validations`) and the interactive console interface. | *Arquitectura Modular: Separación limpia entre el modelo de dominio y la interfaz de consola.*
- **Advanced Regex Validation:** Specialized methods for sanitizing and verifying emails, telephone numbers, and DNI/NIE formats. | *Validación Regex Avanzada: Métodos especializados para sanitizar y verificar emails, teléfonos y DNI.*
- **Interactive Console Engine:** A robust main loop allowing for continuous data entry and real-time validation feedback. | *Motor de Consola Interactivo: Bucle principal que permite entrada de datos continua.*
- **Standardized Error Handling:** Use of custom validation flags and messages to ensure a seamless developer and user experience. | *Manejo de Errores Estandarizado: Uso de flags de validación y mensajes personalizados.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Java 8+
- **Concepts:** Regular Expressions (Regex), Modular Programming, Console I/O.
- **Design Pattern:** Separated Layered Architecture.

---

## 📂 Project Structure | Estructura del Proyecto

- **`/src/model/validations/`**: The core validation engine. | *El motor de validación central.*
- **`/src/view/console/Main.java`**: The primary entry point and interactive interface. | *El punto de entrada principal e interfaz interactiva.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Compile the project using your preferred Java compiler. | *Compila el proyecto usando tu compilador de Java preferido.*
2.  Run the `Main` class. | *Ejecuta la clase `Main`.*
3.  Follow the console prompts to input data and see the modular validation in action. | *Sigue las instrucciones de la consola.*
