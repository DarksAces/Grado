# ☕ Java Logic: Variables & Control Flow (Practica 05)
# ☕ Lógica Java: Variables y Flujo de Control (Practica 05)

## 📋 Description | Descripción

A foundational logic project developed during **1DAM (Tema 2)** that focuses on the core building blocks of **Java Programming**. This practice explores high-precision data types, nested conditional structures, and iterative loops to solve specific computational problems assigned as part of the early curriculum.

Un proyecto de lógica fundamental desarrollado durante **1DAM (Tema 2)** que se centra en los bloques de construcción básicos de la **Programación en Java**. Esta práctica explora tipos de datos de alta precisión, estructuras condicionales anidadas y bucles iterativos.

---

## ✨ Key Features | Características Clave

- **Dynamic Data Types:** Proper implementation of `double`, `float`, and `long` for varied mathematical precision. | *Tipos de Datos Dinámicos: Implementación adecuada de precisión matemática.*
- **Decision Matrix logic:** Use of nested `if-else` and `switch` statements to handle multi-conditional user scenarios. | *Lógica de Matriz de Decisión: Uso de sentencias condicionales anidadas.*
- **Loop Orchestration:** Demonstrates fundamental usage of `for` and `while` for sequence generation and data processing. | *Orquestación de Bucles: Demuestra el uso fundamental de for y while.*
- **Clean Procedural Design:** Focus on readable, well-commented code following early academic standards. | *Diseño Procedimental Limpio: Enfoque en código legible.*
