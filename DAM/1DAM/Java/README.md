# ☕ 1DAM Java: Currículo Fundamental de Backend y Programación

## 📋 Overview | Visión General

Welcome to the **1DAM Java Hub**. This directory orchestrates the first year of Java development, moving from early logic immersion in **Pseint** to industrial-grade backend development with **JDBC** and **Spring Boot**. The curriculum is structured to build a robust mindset in **Object-Oriented Programming (OOP)**, ensuring proficiency in algorithmic efficiency, clean code standards, and database orchestration.

Bienvenido al **Hub de Java de 1DAM**. Este directorio orquesta el primer año de desarrollo en Java, desde la inmersión lógica temprana hasta el desarrollo backend industrial con **JDBC** y **Spring Boot**.
