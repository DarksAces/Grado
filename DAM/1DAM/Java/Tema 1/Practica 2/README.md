# 🧱 JavaLogic Foundations: Núcleo Algorítmico (Practica 2)

## 📋 Description | Descripción

A foundational **Java laboratory** developed in **1DAM (Tema 1)** that focuses on the core mechanics of procedural execution and algorithmic problem-solving. This repository contains specialized exercises for mastering terminal output orchestration (`Pyramid`), calendar logic (`Calendar`), and high-precision string manipulation (`Words10`), serving as the baseline for all subsequent advanced Java tracks.

Un **laboratorio de Java** fundamental desarrollado en **1DAM (Tema 1)** que se centra en las mecánicas core de la ejecución procedimental y la resolución de problemas algorítmicos. Contiene ejercicios para dominar la orquestación de salida por terminal, lógica de calendarios y manipulación de strings.

---

## ✨ Key Features | Características Clave

- **Visual Logic Orchestration:** Implementation of nested loop structures to create dynamic geometric patterns (`Pyramid.java`). | *Orquestación de Lógica Visual: Implementación de bucles anidados.*
- **Calendar & Time Lab:** Procedural logic for handling date formatting and time-driven calculations (`Calendar.java`). | *Laboratorio de Calendario y Tiempo: Lógica para el formato de fechas.*
- **String Manipulation Engine:** Advanced management of character sequences and terminal formatting (`Words10.java`). | *Motor de Manipulación de Strings: Gestión avanzada de secuencias.*
- **Foundational Syntax:** Exploration of primitive data types, basic I/O, and sequential control flow. | *Sintaxis Fundamental: Exploración de tipos de datos primitivos.*
