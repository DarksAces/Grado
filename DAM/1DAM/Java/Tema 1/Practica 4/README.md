# 🚦 LogicGates: Advanced Conditional & Branching Lab (Practica 4)
# 🚦 LogicGates: Laboratorio de Condicionales y Bifurcación (Practica 4)

## 📋 Description | Descripción

A comprehensive **Java laboratory** developed in **1DAM (Tema 1)** dedicated to mastering the decision-making logic of code. **LogicGates** features 9 progressive exercises that explore advanced usage of nested `if-else` statements, `switch` case orchestration, and the integration of multiple logical operators to solve complex real-world branching problems. This module is essential for developing clean, efficient, and robust software control flows.

Un **laboratorio de Java** completo desarrollado en **1DAM (Tema 1)** dedicado a dominar la lógica de toma de decisiones del código. **LogicGates** cuenta con 9 ejercicios progresivos que exploran el uso avanzado de sentencias `if-else` anidadas y orquestación de `switch`.

---

## ✨ Key Features | Características Clave

- **Advanced Decision Modeling:** Logical implementation of diverse real-world scenarios requiring complex branching. | *Modelado de Decisiones Avanzado: Implementación lógica de diversos escenarios.*
- **Switch-Case Orchestration:** Specialized laboratory for multi-branch selection and cleaner code structure. | *Orquestación de Switch-Case: Laboratorio especializado para la selección de múltiples ramas.*
- **Logical Operator Synergy:** Recursive usage of `&&`, `||`, and `!` to create high-precision validation logic. | *Sinergia de Operadores Lógicos: Uso recursivo de operadores.*
- **Interactive User Input:** Integration with `System.in` for real-time user-driven logic path selection. | *Entrada de Usuario Interactiva: Selección de ruta de lógica en tiempo real.*
