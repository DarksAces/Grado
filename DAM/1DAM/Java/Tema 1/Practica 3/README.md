# 🧩 LoopCraft: Iterative Control & Logical Lab (Practica 3)
# 🧩 LoopCraft: Laboratorio de Control Iterativo y Lógica (Practica 3)

## 📋 Description | Descripción

An essential **Java laboratory** developed in **1DAM (Tema 1)** that covers the mastery of control structures. **LoopCraft** consists of 6 progressive exercises focusing on the orchestration of `for`, `while`, and `do-while` loops to solve complex arithmetic and visual problems. This module is critical for understanding the foundations of iterative logic and program efficiency in a procedural Java environment.

Un **laboratorio de Java** esencial desarrollado en **1DAM (Tema 1)** que cubre el dominio de las estructuras de control. **LoopCraft** consiste en 6 ejercicios progresivos centrados en la orquestación de bucles `for`, `while` y `do-while` para resolver problemas aritméticos y visuales complejos.

---

## ✨ Key Features | Características Clave

- **Iterative Logic Mastery:** Intensive usage of loop paradigms to process data sequences and generate dynamic outputs. | *Dominio de Lógica Iterativa: Uso intensivo de paradigmas de bucles.*
- **Arithmetic Edge Cases:** Specialized logic for handling prime numbers, series calculations, and mathematical validations. | *Casos Borde Aritméticos: Lógica especializada para números primos y cálculos de series.*
- **Terminal Design Patterns:** Creation of structured reports and visual terminal representations using iterative logic. | *Patrones de Diseño de Terminal: Creación de informes estructurados.*
- **Input Orchestration:** Integration of `Scanner` logic with loop structures to create interactive CLI sessions. | *Orquestación de Entrada: Integración de Scanner.*

## 🛠️ Tech Stack | Tecnologías

- **Language:** Java 8+.
- **IDE Support:** NetBeans / VS Code.
