# 🚗 DriveLogic: Object-Oriented Vehicle Management (Java)
# 🚗 DriveLogic: Gestión de Vehículos Orientada a Objetos (Java)

## 📋 Description | Descripción

A foundational **Java** project developed in **1DAM** focusing on the core principles of **Object-Oriented Programming (OOP)** within the context of an automotive management system. **DriveLogic** implements a robust class hierarchy to model various vehicle types, mastering concepts like inheritance, data encapsulation (`private`/`public` access), and constructor orchestration.

Un proyecto fundamental de **Java** desarrollado en **1DAM** centrado en los principios core de la **Programación Orientada a Objetos (POO)**. **DriveLogic** implementa una jerarquía de clases robusta para modelar varios tipos de vehículos, dominando conceptos como la herencia y la encapsulación de datos.

---

## ✨ Key Features | Características Clave

- **OO Hierarchy Design:** Specialized classes for different vehicle categories, showcasing the reuse of attributes and methods. | *Diseño de Jerarquía POO: Clases especializadas que muestran la reutilización de código.*
- **Data Encapsulation Lab:** Practical implementation of Getters, Setters, and access level management to ensure data integrity. | *Laboratorio de Encapsulación: Implementación práctica de Getters y Setters.*
- **State Orchestration:** Real-time management of vehicle attributes (Speed, Fuel, Model) through method interaction. | *Orquestación de Estado: Gestión de atributos en tiempo real.*
- **NetBeans / Ant Build Support:** Pre-configured `build.xml` for immediate compilation and deployment. | *Soporte para NetBeans: Compilación inmediata.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Java 8 / 11.
- **Concepts:** Inheritance, Encapsulation, Constructors, Class Modeling.
- **IDE Support:** NetBeans / Eclipse / IntelliJ.

## 📂 Project Structure | Estructura del Proyecto

- **`src/practicavehiculos/`**: The main execution engine and user interaction logic. | *El motor de ejecución principal.*
