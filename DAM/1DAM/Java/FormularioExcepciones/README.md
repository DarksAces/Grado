# 🛡️ GuardLogic: Advanced Exception Handling & UI Validation
# 🛡️ GuardLogic: Gestión Avanzada de Excepciones y Validación de UI

## 📋 Description | Descripción

A specialized **Java Software Engineering** laboratory developed in **1DAM** focusing on the robust implementation of **Exception Handling** within a graphical context. **GuardLogic** implements a sophisticated multi-layered validation system (following the MVC pattern) to capture, process, and gracefully respond to programmatic and user-driven errors. This project masters the creation of custom Exception hierarchies, `try-catch-finally` orchestration, and the integration of defensive programming patterns to ensure system stability.

Un laboratorio especializado de **Ingeniería de Software en Java** desarrollado en **1DAM** centrado en la implementación robusta de la **Gestión de Excepciones**. **GuardLogic** implementa un sistema sofisticado de validación en múltiples capas (siguiendo el patrón MVC).

---

## ✨ Key Features | Características Clave

- **Custom Exception Orchestration:** specialized `Exceptions` package for defining domain-specific error states. | *Orquestación de Excepciones Personalizadas: Paquete especializado para definir estados de error.*
- **MVC Defensive Architecture:** Clean separation between logical data models, visual input views, and the underlying error-trapping engine. | *Arquitectura Defensiva MVC: Separación limpia entre modelos, vistas y motores.*
- **High-Precision Data Validation:** Advanced logic for capturing and mitigating out-of-bounds metrics and invalid arithmetic operations. | *Validación de Datos de Alta Precisión.*
- **Robust User Feedback:** Direct integration between technical exceptions and user-friendly visual reports. | *Feedback de Usuario Robusto.*

## 🛠️ Tech Stack | Tecnologías

## 📂 Project Structure | Estructura del Proyecto

- **`src/Exceptions/`**: The core repository for custom Error definitions and hierarchy. | *El repositorio core para definiciones de errores.*
- **`src/model/`**: Dynamic data entities representing the system state and logic. | *Entidades de datos dinámicas.*
- **`src/view/`**: Interactive user interface layer for terminal/GUI based input. | *Capa de interfaz interactiva.*
