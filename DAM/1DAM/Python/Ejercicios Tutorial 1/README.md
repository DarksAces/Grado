# 🐍 PyIntro: Programación Fundamental en Python (Tutorial 1)

## 📋 Description | Descripción

The primary **Python entry point** for the **1DAM** curriculum. This module contains 23 progressive exercises designed to master the syntax and logical paradigms of Python. It covers the evolution from a simple "Hello World" to complex data management using **Lists** and **Tuples** for simulating musical playlists and videogame inventories.

El punto de entrada principal a **Python** en el currículo de **1DAM**. Este módulo contiene 23 ejercicios progresivos diseñados para dominar la sintaxis y los paradigmas lógicos. Cubre la evolución desde un "Hola Mundo" hasta la gestión compleja de datos usando **Listas** y **Tuplas**.

---

## ✨ Key Features | Características Clave

- **Core Syntax Mastery:** Detailed exploration of variables, arithmetic operations, and conditional branching (`if`, `elif`, `else`). | *Dominio de Sintaxis Core: Exploración detallada de variables y condicionales.*
- **Data Structure Foundations:** Indvidiual laboratories for working with **Lists** (dynamic) and **Tuplas** (immutable). | *Fundamentos de Estructuras de Datos: Laboratorios para Listas y Tuplas.*
- **Interactive Logic:** Implementation of classic games (Adivina número) and decision systems (Recomendación música/ropa). | *Lógica Interactiva: Implementación de juegos clásicos.*
- **Real-world Simulations:** Early usage of functional modules for handling **Event Organizations** and **Playlists**. | *Simulaciones del mundo real: Manejo de eventos y listas de reproducción.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Python 3.x.
- **Concepts:** Procedural programming, Sequential flow, Mutable vs Immutable data.

---

## 📂 Project Structure | Estructura del Proyecto

- **`1) Hola Mundo.py`**: The absolute beginning. | *El inicio absoluto.*
- **`13) Quiz.py`**: A complete interactive knowledge assessment tool. | *Una herramienta completa de evaluación interactiva.*
- **`20) Metodos avanzados de listas.py`**: Mastering list orchestration and manipulation. | *Maestría en orquestación y manipulación de listas.*
- **`23) inventario videojuego.py`**: The culmination of the tutorial, simulating a complex game state. | *Simulación de un estado de juego complejo.*
