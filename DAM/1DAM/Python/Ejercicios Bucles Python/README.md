# 🐍 PyFoundations: Laboratorio Integral de Lógica y Datos en Python

## 📋 Description | Descripción

A massive collection of **24 specialized exercises** developed in **1DAM** that covers the absolute core of **Python Programming**. This laboratory transitions from basic control flows to advanced data serialization using **JSON** and **XML**. It is structured as a progressive curriculum, moving from simple loops to complex system simulations like music library managers and videogame battle engines.

Una colección masiva de **24 ejercicios especializados** desarrollados en **1DAM** que cubre el núcleo absoluto de la **Programación en Python**. Este laboratorio hace la transición de flujos de control básicos a la serialización avanzada de datos usando **JSON** y **XML**.

---

## ✨ Key Features | Características Clave

- **Algorithmic Mastery:** 10+ modules dedicated to `for` and `while` loop optimization and complex branching. | *Maestría Algorítmica: Más de 10 módulos dedicados a la optimización de bucles.*
- **Functional Programming:** Progressive introduction to function definitions, parameters, and return values. | *Programación Funcional: Introducción progresiva a definiciones de funciones.*
- **Data Serialization Lab:** Practical implementation of **JSON** and **XML** read/write operations for persistent storage. | *Laboratorio de Serialización: Implementación práctica de JSON y XML.*
- **Musical & Gaming Simulations:** Real-world applications including a Musical Scale Generator, Battle Simulator, and Library Manager. | *Simulaciones Musicales y de Juegos: Aplicaciones reales.*

## 🛠️ Tech Stack | Tecnologías

- **Language:** Python 3.x.
- **Modules:** `json`, `xml.etree.ElementTree`, `random`, `math`.
- **Concepts:** Procedural programming, Data persistence, Schema comparison (JSON vs XML).
