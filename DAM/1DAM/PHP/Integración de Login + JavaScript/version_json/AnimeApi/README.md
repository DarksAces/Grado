# 📂 AnimeQuest: Orquestación Multimedia Basada en JSON (PHP)

## 📋 Description | Descripción

A specialized **Full-stack PHP** laboratory developed in **1DAM** focusing on the orchestration of semi-structured data using **JSON** as a persistence layer. **AnimeQuest (vJSON)** implements a high-performance media catalog where data is fetched directly from local `.json` repositories. This project masters the usage of `json_decode`, array mapping logic, and the integration of asynchronous JavaScript for real-time data delivery and visual rendering.

Un laboratorio especializado de **PHP Full-stack** desarrollado en **1DAM** centrado en la orquestación de datos semi-estratificados usando **JSON** como capa de persistencia. **AnimeQuest (vJSON)** implementa un catálogo multimedia de alto rendimiento.

---

## ✨ Key Features | Características Clave

- **JSON Data Orchestration:** Professional usage of native PHP JSON functions to manage and render local data repositories. | *Orquestación de Datos JSON: Uso profesional de funciones nativas de PHP.*
- **Logic Mapping Engine:** Advanced array orchestration to translate raw JSON objects into visual character cards. | *Motor de Mapeo Lógico: Orquestación de arrays.*
- **Interactive JS Logic:** Asynchronous frontend logic for dynamic data delivery without full-page reloads. | *Lógica JS Interactiva: Entrega de datos dinámica.*
- **Standardized Asset Hub:** Organized `/CSS/` and `/JS/` modules to ensure clean code separation and professional UI branding. | *Hub de Activos Estandarizado.*

## 🚀 How to Run | Cómo Ejecutar

1.  Deploy the folder to a PHP-compatible server (e.g., XAMPP/Apache). | *Despliega la carpeta en un servidor PHP.*
2.  Ensure the `.json` data files are present in the designated resource directory. | *Asegúrate de que los archivos JSON estén presentes.*
3.  Open the index file in your browser. | *Abre el archivo index en tu navegador.*
4.  Interact with the catalog to observe the dynamic JSON data loading. | *Interactúa con el catálogo.*
