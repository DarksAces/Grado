# 🍿 AnimeStream: Orquestación Multimedia Basada en BD (PHP)

## 📋 Description | Descripción

A specialized **Full-stack PHP** laboratory developed in **1DAM** focusing on the integration of dynamic content from a relational database. **AnimeStream (vBD)** implements a robust media catalog where data is orchestrated from a **MySQL/MariaDB** backend. This project masters the usage of PHP's `PDO` or `mysqli` extensions for high-performance data retrieval, combined with interactive JavaScript and professional CSS layout design to deliver a seamless user experience.

Un laboratorio especializado de **PHP Full-stack** desarrollado en **1DAM** centrado en la integración de contenido dinámico desde una base de datos relacional. **AnimeStream (vBD)** implementa un catálogo multimedia robusto orquestado desde un backend MySQL.

---

## ✨ Key Features | Características Clave

- **Relational Data Orchestration:** Professional usage of SQL queries to fetch and render character-themed media assets. | *Orquestación de Datos Relacionales: Uso profesional de consultas SQL.*
- **Interactive JS Logic:** Asynchronous frontend logic for dynamic DOM updates based on server-side queries. | *Lógica JS Interactiva: Actualizaciones dinámicas del DOM.*
- **Secure Backend Design:** Implementation of basic security patterns for database connection management. | *Diseño de Backend Seguro.*
- **Responsive Media Hub:** Professional `/CSS/` and `/HTML/` orchestration to ensure high visual quality across devices. | *Hub Multimedia Responsivo.*

## 🚀 How to Run | Cómo Ejecutar

1.  Configure your MySQL database with the corresponding anime schema. | *Configura tu base de datos MySQL.*
2.  Update the connection parameters in the PHP source files. | *Actualiza los parámetros de conexión.*
3.  Deploy the folder to a PHP-compatible server (e.g., XAMPP/Apache). | *Despliega la carpeta en un servidor PHP.*
4.  Open the index file in your browser to interact with the database-driven catalog. | *Abre el archivo index en tu navegador.*
