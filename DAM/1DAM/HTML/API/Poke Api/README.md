# 🎮 PokéAPI Explorer: Dynamic Frontend Data Integration
# 🎮 PokéAPI Explorer: Integración Dinámica de Datos Frontend

## 📋 Description | Descripción

A reactive web application developed in **1DAM** that consumes the public [PokéAPI](https://pokeapi.co/). This project demonstrates advanced asynchronous programming in JavaScript (AJAX/Fetch), dynamic DOM manipulation, and the implementation of a responsive search engine for a massive dataset.

Una aplicación web reactiva desarrollada en **1DAM** que consume la [PokéAPI](https://pokeapi.co/) pública. Este proyecto demuestra la programación asíncrona avanzada en JavaScript (AJAX/Fetch), manipulación dinámica del DOM y la implementación de un buscador responsivo para un conjunto masivo de datos.

---

## ✨ Key Features | Características Clave

- **Real-time API Consumption:** High-performance data fetching using `async/await` and the Fetch API. | *Consumo de API en Tiempo Real: Obtención de datos usando Fetch.*
- **Interactive Pokédex:** A dynamic interface that renders stats, types, and high-quality sprites for any Pokémon searched. | *Pokédex Interactiva: Interfaz dinámica que renderiza estadísticas y sprites.*
- **Asset Separation:** Clean directory structure isolating Logic (JS), Structure (HTML), and Styling (CSS). | *Separación de Activos: Estructura limpia que aísla Lógica, Estructura y Estilo.*
- **Error Handling:** Robust feedback for invalid searches or network connectivity issues. | *Manejo de Errores: Feedback robusto para búsquedas inválidas o fallos de red.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** JavaScript (ES6+), HTML5, CSS3.
- **REST API:** PokéAPI v2.
- **Concepts:** Promises, JSON parsing, Async I/O.

---

## 📂 Project Structure | Estructura del Proyecto

- **`/HTML/`**: Skeleton pages and result containers. | *Páginas esqueleto y contenedores de resultados.*
- **`/CSS/`**: Custom styling for cards and specific animations. | *Estilo para tarjetas y animaciones.*
- **`/JavaScript/`**: The core API bridge and DOM update engine. | *El puente de API core y motor de actualización del DOM.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open any HTML file in the `/HTML/` directory using a browser. | *Abre cualquier archivo HTML en el directorio `/HTML/`.*
2.  Use the search bar to enter a Pokémon name or ID. | *Usa la barra de búsqueda para ingresar un nombre o ID.*
3.  Explore the generated cards and statistics. | *Explora las tarjetas y estadísticas generadas.*
