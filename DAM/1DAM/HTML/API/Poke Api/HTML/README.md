# 🐾 Interactive Pokédex | Pokédex Interactiva

## 📋 Description | Descripción
**EN:** This project is a dynamic web application designed to explore and demonstrate the integration of the **PokeAPI**. It serves as a comprehensive digital encyclopedia where users can browse Pokémon data, including types, evolutionary chains, habitats, and special items, all through a clean and functional interface.

**ES:** Este proyecto es una aplicación web dinámica diseñada para explorar y demostrar la integración con la **PokeAPI**. Funciona como una enciclopedia digital completa donde los usuarios pueden consultar datos de Pokémon, incluyendo tipos, cadenas evolutivas, hábitats y objetos especiales, todo a través de una interfaz limpia y funcional.

- **Categorized Navigation:** Specialized sections for Habitats and Items (Objects). | **Navegación Categorizada:** Secciones especializadas para Hábitats y Objetos.
- **Evolutionary Tracking:** Visualizes the evolution chain for each Pokémon. | **Seguimiento Evolutivo:** Visualiza la cadena de evolución de cada Pokémon.
- **Responsive Design:** Table-based layout optimized for data readability. | **Diseño Responsivo:** Diseño basado en tablas optimizado para la legibilidad de los datos.
