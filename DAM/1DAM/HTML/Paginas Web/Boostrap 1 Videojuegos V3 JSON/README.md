# 🎮 GameHub: Portal de Videojuegos con Bootstrap (1DAM)

## 📋 Description | Descripción

A multi-version web project developed in **1DAM** focusing on modern CSS frameworks and dynamic content loading. **GameHub** demonstrates the use of **Bootstrap 5** for responsive layout design, combined with a **JSON-based content engine** to dynamically render videogame metadata and galleries.

Un proyecto web multiversión desarrollado en **1DAM** enfocado en frameworks CSS modernos y carga de contenido dinámico. **GameHub** demuestra el uso de **Bootstrap 5** para diseño responsivo, combinado con un **motor de contenido basado en JSON** para renderizar dinámicamente metadatos de videojuegos.

---

## ✨ Key Features | Características Clave

- **Bootstrap 5 Integration:** Extensive use of the Bootstrap grid system, navigation bars, and specialized card components. | *Integración Bootstrap 5: Uso exhaustivo del sistema de rejilla y componentes.*
- **Dynamic JSON Engine (V3):** Evolution from static pages to a JavaScript-driven architecture that fetches game data from local JSON files. | *Motor JSON Dinámico (V3): Evolución a una arquitectura basada en JavaScript.*
- **Integrated Multimedia Gallery:** Specialized `/Fotos/` and `/html/` modules for high-quality game previews and detailed descriptions. | *Galería Multimedia Integrada: Módulos para previsualizaciones de juegos.*
- **Responsive Mobile-First Design:** Optimized for seamless viewing across smartphones, tablets, and desktops. | *Diseño Responsive Mobile-First: Optimizado para todos los dispositivos.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** HTML5, CSS3, JavaScript (ES6).
- **Framework:** Bootstrap 5.
- **Data Persistence:** JSON (Static NoSQL).

---

## 📂 Project Structure | Estructura del Proyecto

- **`Index.html`**: The main landing page and Bootstrap entry point. | *La página de aterrizaje principal.*
- **`/JSON/`**: Data files containing videogame titles, descriptions, and metadata. | *Archivos de datos con títulos y descripciones.*
- **`/js/`**: Application logic for dynamic content rendering. | *Lógica de aplicación para renderizado dinámico.*
- **`/css/`**: Custom overrides and Bootstrap integrations. | *Sobrescrituras personalizadas e integración de Bootstrap.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the `Index.html` file in a browser. | *Abre el archivo `Index.html` en un navegador.*
2.  Explore the different videogame categories. | *Explora las categorías de videojuegos.*
3.  Observe how the content is loaded from the JSON files in the V3 version. | *Observa cómo se carga el contenido desde los archivos JSON.*
