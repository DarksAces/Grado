# 🚀 StartupNexus: Multi-Format Event Ecosystem (1DAM)
# 🚀 StartupNexus: Ecosistema de Eventos Multi-Formato (1DAM)

## 📋 Description | Descripción

An advanced **1DAM** educational project focused on interoperability between different data exchange formats within a web environment. **StartupNexus** is an event management portal that demonstrates the consumption and rendering of data from both **JSON** and **XML** sources, providing a comprehensive exploration of AJAX/Fetch and the legacy XML DOM API.

Un proyecto educativo avanzado de **1DAM** centrado en la interoperabilidad entre diferentes formatos de intercambio de datos. **StartupNexus** es un portal de gestión de eventos que demuestra el consumo y renderizado de datos de fuentes **JSON** y **XML**.

---

## ✨ Key Features | Características Clave

- **Dual-Protocol Data Engine:** Concurrent support for modern **JSON** parsing and legacy **XML** data ingestion. | *Motor de Datos de Protocolo Dual: Soporte concurrente para JSON y XML.*
- **RSS & Atom Feeds:** Integrated sub-module for handling real-time syndication feeds (`Evento Startups Feeds RSS y Atom`). | *Feeds RSS y Atom: Módulo integrado para el manejo de sindicación.*
- **Responsive Event Dashboard:** A clean, professional landing page (`Index.html`) that serves as the primary visual orchestrator. | *Dashboard de Eventos Responsivo: Una landing page profesional.*
- **Modular Asset Pipeline:** Isolated directories for Logic (JS), Structure (HTML), Styling (CSS), and Data (XML/JSON). | *Pipeline de Activos Modular: Directorios aislados para cada componente.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** HTML5, CSS3, JavaScript (ES6+).
- **Data Formats:** JSON, XML (RSS/Atom).
- **Core Concepts:** AJAX, Fetch API, XML DOM Parsing, Data Interoperability.

---

## 📂 Project Structure | Estructura del Proyecto

- **`Index.html`**: The primary gateway to the event ecosystem. | *La puerta de entrada principal.*
- **`/JSON/` & `/XML/`**: Dedicated storage for event payloads and structural metadata. | *Almacenamiento dedicado para payloads de eventos.*
- **`/JavaScript/`**: The core logic engine that bridges the raw data with the UI. | *El motor de lógica central.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the `Index.html` file in a browser. | *Abre el archivo `index.html` en un navegador.*
2.  Observe how the application fetches and displays data from the different sources. | *Observa cómo la aplicación obtiene y muestra los datos.*
3.  Check the `/XML/` folder to analyze the structural differences compared to JSON. | *Compara las estructuras de XML y JSON.*
