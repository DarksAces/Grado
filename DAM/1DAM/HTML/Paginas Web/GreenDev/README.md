# 🌿 GreenDev: Portal Web Enfocado en Sostenibilidad (1DAM)

## 📋 Description | Descripción

A professional multi-page website project developed in **1DAM** using modern web technologies. **GreenDev** is a proof-of-concept for a sustainability-focused digital brand, demonstrating proficiency in semantic HTML5, advanced CSS3 styling, and basic JavaScript interactions for a seamless user experience.

Un proyecto de sitio web multipágina profesional desarrollado en **1DAM** usando tecnologías web modernas. **GreenDev** es una prueba de concepto para una marca digital enfocada en la sostenibilidad, demostrando competencia en HTML5 semántico, estilado avanzado con CSS3 e interacciones básicas con JavaScript.

---

## ✨ Key Features | Características Clave

- **Full-Responsive Layout:** Designed to work across different viewport sizes using native CSS techniques. | *Diseño Totalmente Responsivo: Diseñado para funcionar en diferentes tamaños de pantalla.*
- **Asset Modularization:** Clean separation of concerns with dedicated directories for stylesheets, scripts, and HTML fragments. | *Modularización de Activos: Separación limpia de estilos, scripts y fragmentos HTML.*
- **Interactive Navigation:** Professional header and footer systems integrated across all sub-pages. | *Navegación Interactiva: Sistemas profesionales de cabecera y pie de página.*
- **Eco-themed Design System:** Custom color palette and typography selections aligned with environmental branding. | *Sistema de Diseño Eco: Paleta de colores y tipografía personalizadas.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** HTML5, CSS3, JavaScript (ES6).
- **Concepts:** Flexbox, Grid, DOM manipulation, Asset linking.

---

## 📂 Project Structure | Estructura del Proyecto

- **`Index.html`**: The primary entry point and landing page. | *El punto de entrada principal y página de aterrizaje.*
- **`/CSS/`**: Modular stylesheets handling layout and typography. | *Hojas de estilo modulares.*
- **`/JavaScript/`**: Frontend logic for basic interactivity and animations. | *Lógica frontend para interactividad básica.*
- **`/Html/`**: Secondary pages and modular content blocks. | *Páginas secundarias y bloques de contenido.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open `Index.html` in any modern web browser. | *Abre `Index.html` en cualquier navegador web moderno.*
2.  Navigate through the different sections using the integrated menu. | *Navega por las secciones usando el menú integrado.*
