# 🧠 Simon Game: Logic & Memory in JS
# 🧠 Juego Simon: Lógica y Memoria en JS

## 📋 Description | Descripción

An interactive web-based version of the classic **Simon Game**. This project focuses on DOM manipulation, time-based events in JavaScript, and game logic state management. It challenges users to repeat an ever-growing sequence of light and sound signals.

Una versión web interactiva del clásico **Juego Simon**. Este proyecto se centra en la manipulación del DOM, eventos basados en el tiempo en JavaScript y la gestión del estado de la lógica del juego. Desafía a los usuarios a repetir una secuencia cada vez mayor de señales luminosas y sonoras.

---

## ✨ Key Features | Características Clave

- **Dynamic Sequence Generation:** The algorithm generates a random sequence that grows with each successfully completed level. | *Generación de Secuencia Dinámica: El algoritmo genera una secuencia aleatoria que crece con cada nivel completado con éxito.*
- **Timed Level System:** Includes a countdown timer for the player's turn to increase difficulty and pressure. | *Sistema de Niveles con Tiempo: Incluye un temporizador de cuenta regresiva para el turno del jugador para aumentar la dificultad y la presión.*
- **Visual Feedback:** Smooth CSS transitions and state changes when tiles are activated by the AI or the user. | *Retroalimentación Visual: Transiciones CSS suaves y cambios de estado cuando las fichas son activadas por la IA o el usuario.*
- **Robust State Management:** Handles "Espera a la computadora" (Wait for computer) and user turn states to prevent input errors. | *Gestión de Estado Robusta: Maneja los estados de "Espera a la computadora" y turno del usuario para evitar errores de entrada.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** JavaScript (Vanilla ES6)
- **Frontend:** HTML5, CSS3
- **Concepts:** `setInterval`, `setTimeout`, Event Listeners, Data-attributes.

---

## 📂 Project Structure | Estructura del Proyecto

- **`index.html`**: Core structure and tile layout. | *Estructura central y diseño de las fichas.*
- **`/JavaScript/simon.js`**: Game engine, timer logic, and sequence management. | *Motor del juego, lógica del temporizador y gestión de secuencias.*
- **`/Css/`**: Styles for the board and activation animations. | *Estilos para el tablero y animaciones de activación.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open `index.html` directly in any modern web browser. | *Abre `index.html` directamente en cualquier navegador web moderno.*
2.  Click the **Start Button** to begin the sequence. | *Haz clic en el **Botón de Inicio** para empezar la secuencia.*
3.  Pay attention to the flashes and repeat the sequence before the timer runs out. | *Presta atención a los destellos y repite la secuencia antes de que se agote el tiempo.*
