# 🚀 DAM: Multiplatform Application Development | Desarrollo de Aplicaciones Multiplataforma

Welcome to the **DAM** section. This degree focuses on high-level software development for multiple platforms (Desktop, Web, Mobile).

Bienvenido a la sección de **DAM**. Este grado se enfoca en el desarrollo de software de alto nivel para múltiples plataformas (Escritorio, Web, Móvil).

---

## 📅 Course Structure | Estructura del Curso

### [1️⃣ 1st Year | 1er Año (1DAM)](1DAM/README.md)
Foundations of coding and database management.
*Bases de la programación y gestión de bases de datos.*

### [2️⃣ 2nd Year | 2do Año (2DAM)](2DAM/README.md)
Advanced development, security, and professional project management.
*Desarrollo avanzado, seguridad y gestión de proyectos profesionales.*

## 🛠️ Main Tech Stack | Tecnologías Principales

- **Programming:** Java, Python, C#, PHP, Swift/Kotlin (Mobile).
- **Architecture:** API REST, MVC, Asynchronicity, SQL/NoSQL.
- **Tools:** Git, Visual Studio, Android Studio, XAMPP.
