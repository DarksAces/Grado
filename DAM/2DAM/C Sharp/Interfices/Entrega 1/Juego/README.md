# 🎮 CSharpArcade: Classic Game Suite (Entrega 1)
# 🎮 CSharpArcade: Suite de Juegos Clásicos (Entrega 1)

## 📋 Description | Descripción

A fun and educational **C# Console Application** suite developed as the first delivery for **2DAM**. This project implements two legendary games—**Tic-Tac-Toe** and **Rock-Paper-Scissors**—focusing on clean CLI logic, two-player synchronization, and robust win-condition algorithms using modern C# features.

Una suite de **Aplicaciones de Consola en C#** divertida y educativa desarrollada como la primera entrega de **2DAM**. Este proyecto implementa dos juegos legendarios—**Tres en Raya** y **Piedra, Papel o Tijera**—enfocándose en lógica de CLI limpia y algoritmos de condición de victoria robustos.

---

## ✨ Key Features | Características Clave

- **Tic-Tac-Toe Engine:** Advanced 3x3 grid management with automated move validation and win detection. | *Motor de Tres en Raya: Gestión avanzada de rejilla 3x3 con validación de movimientos.*
- **Rock-Paper-Scissors Simulation:** Dynamic input parsing and randomized outcomes for player vs CPU or local PvP. | *Simulación de Piedra, Papel o Tijera: Análisis de entrada dinámico.*
- **Interactive CLI UI:** Optimized terminal output for clear game states and player instructions. | *IU de Consola Interactiva: Salida de terminal optimizada.*
- **Clean Object-Oriented Logic:** Decoupled game modules represented in specialized `.cs` files. | *Lógica POO Limpia: Módulos desacoplados.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** C# 10+ (.NET 6/7).
- **Environment:** Console Application (CLI).
- **Concepts:** Multidimensional Arrays, Conditional Logic, Game Loop, Input Sanitization.

---

## 📂 Project Structure | Estructura del Proyecto

- **`TicTacToe.cs`**: The core logic for the 3x3 strategy game. | *La lógica central para el juego de estrategia.*
- **`PiedraPapelTijeras.cs`**: Implementation of the classic decision game. | *Implementación del clásico juego de decisiones.*
- **`Program.cs`**: The primary game selector and launcher. | *El selector y lanzador de juegos principal.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the project in **Visual Studio** or **VS Code**. | *Abre el proyecto en **Visual Studio** o **VS Code**.*
2.  Run the application using the terminal: `dotnet run`. | *Ejecuta la aplicación usando `dotnet run`.*
3.  Select which game you want to play from the main menu. | *Selecciona el juego que deseas jugar.*
4.  Follow the on-screen instructions to play! | *¡Sigue las instrucciones en pantalla!*
