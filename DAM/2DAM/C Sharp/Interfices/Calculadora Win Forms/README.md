# 🧮 SharpCalc: Calculadora Profesional en C# WinForms

## 📋 Description | Descripción

A high-performance **desktop application** developed in **2DAM** using **C#** and the **Windows Forms (WinForms)** framework. **SharpCalc** is a fully functional mathematical engine featuring a robust UI, advanced event handling for numeric operations, and precise decimal management. It serves as a practical implementation of event-driven programming and object-oriented architectural principles in the .NET ecosystem.

Una aplicación de escritorio de alto rendimiento desarrollada en **2DAM** usando **C#** y el framework **Windows Forms**. **SharpCalc** es un motor matemático completamente funcional con una interfaz robusta, manejo de eventos avanzado para operaciones numéricas y gestión precisa de decimales.

---

## ✨ Key Features | Características Clave

- **Advanced Event Orchestration:** Specialized handling of button click events and keyboard input synchronization. | *Orquestación de Eventos Avanzada: Manejo especializado de clics y sincronización de teclado.*
- **Recursive Logic Design:** Implementation of mathematical precedence and sequential chain operations. | *Diseño de Lógica Recursiva: Implementación de precedencia matemática.*
- **High-Density UI:** Clean, responsive interface designed with the **WinForms Designer** (13KB+ backing logic), ensuring a native desktop feel. | *UI de Alta Densidad: Interfaz limpia y responsiva.*
- **Floating-Point Precision:** Optimized for financial and scientific calculations using C# `decimal` and `double` types. | *Precisión de Punto Flotante: Optimizado para cálculos precisos.*

1.  Open the `WinFormsApp1.sln` solution file in **Visual Studio**. | *Abre el archivo de solución en **Visual Studio**.*
