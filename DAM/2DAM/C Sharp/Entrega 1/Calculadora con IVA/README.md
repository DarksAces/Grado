# 👔 TaxCore: Business Logic & VAT Calculator (C#)
# 👔 TaxCore: Lógica de Negocio y Calculadora de IVA (C#)

## 📋 Description | Descripción

A specialized **C# Console Application** developed for **2DAM (Entrega 1)** that focuses on financial business logic and precise data orchestration. **TaxCore** implements a multi-functional VAT (IVA) calculator, allowing for the processing of diverse item categories, dynamic tax rates, and structured financial summary generation within a high-performance CLI environment.

Una **Aplicación de Consola en C#** especializada desarrollada para **2DAM (Entrega 1)** que se centra en la lógica de negocio financiera. **TaxCore** implementa una calculadora de IVA multifuncional, permitiendo el procesamiento de diversas categorías de artículos y tasas impositivas dinámicas.

---

## ✨ Key Features | Características Clave

- **Dynamic VAT Calculation:** Specialized logic for applying different tax brackets (General, Reduced, Super-reduced). | *Cálculo de IVA Dinámico: Lógica especializada para aplicar diferentes tramos impositivos.*
- **Financial Orchestration:** Ability to process multiple items in a single session with cumulative auditing. | *Orquestación Financiera: Capacidad de procesar múltiples artículos con auditoría acumulativa.*
- **Advanced CLI Interaction:** Structured user input validation and formatted tabular report output. | *Interacción CLI Avanzada: Validación estructurada de entrada.*
- **Precision Floating Point:** Uses C# `decimal` types for high-accuracy financial rounding. | *Precisión de Punto Flotante: Uso de tipos decimal para alta precisión.*
