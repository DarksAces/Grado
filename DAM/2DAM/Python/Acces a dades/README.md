# 💾 2DAM Acceso a Datos: Inteligencia Artificial y Persistencia Industrial

## 📋 Overview | Visión General

Welcome to the **Data Access (Acces a Dades)** repository. This directory orchestrates the first year of professional-grade Python applications, focusing on the synergy between advanced data persistence and high-performance **Artificial Intelligence** integration. The curriculum covers the evolution from basic algorithmic logic to the creation of interactive **Computer Vision** tools, secure **Biometric Authentication**, and industrial **Web APIs** using modern ORM patterns.

Bienvenido al repositorio de **Acceso a Datos**. Este directorio orquesta el primer año de aplicaciones profesionales de Python, centrándose en la sinergia entre la persistencia de datos avanzada y la integración de IA.

---

## 📂 Curriculum Modules | Módulos del Currículo

- **[Primer Trimestre](Primer%20Trimestre/)**: Foundational Python laboratories for mastering complex algorithmic solutions and early DAO patterns. | *Laboratorios fundamentales de Python.*
- **[Segundo Trimestre](Segundo%20Trimestre/)**: Advanced module focusing on:
    - **Flask & SQLAlchemy:** High-performance REST APIs with professional database orchestration. | *APIs REST con orquestación de DB.*
    - **Reconocimiento Facial (BioPass):** Industrial facial biometric authentication using the MediaPipe ecosystem. | *Reconocimiento facial biométrico.*
- **[Tercer Trimestre](Tercer%20Trimestre/)**: Cutting-edge AI implementation:
    - **VolumeHandControl:** Computer Vision module for gesture-based hardware orchestration. | *Control de volumen mediante gestos e IA.*

## 🛠️ Tech Stack | Tecnologías

- **Language:** Python 3.10+.
- **AI/ML:** OpenCV, MediaPipe, Deep Learning foundations.
- **Backend:** Flask, SQLAlchemy (ORM), JWT.
- **DBMS:** MySQL / MariaDB / SQLite.
