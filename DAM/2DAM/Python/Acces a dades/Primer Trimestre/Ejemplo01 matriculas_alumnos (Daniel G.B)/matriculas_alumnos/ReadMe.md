# Matriculas Alumnos

Este programa permite gestionar un registro simple de alumnos matriculados utilizando un archivo de texto.

El codigo crea un menu que permite:

1. Matricular alumnos, guardando su nombre en un archivo llamado `alumnos.txt`.
2. Listar todos los alumnos matriculados leyendo el contenido del archivo.
3. Eliminar el archivo de alumnos si se desea comenzar de nuevo.
4. Salir del programa.

Cada vez que se matricula un alumno, su nombre se guarda en una nueva linea dentro del archivo de texto.  
Si el archivo no existe, se crea automaticamente.  
Todas las operaciones se realizan usando funciones basicas de manejo de ficheros en Python.
