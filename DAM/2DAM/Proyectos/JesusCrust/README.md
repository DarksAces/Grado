# 🧙‍♂️ JesusCrust: The Muggle's Loop Challenge
# 🧙‍♂️ JesusCrust: El Desafío del Bucle para Muggles

## 📋 Description | Descripción

A fun and interactive **Python** logic game inspired by the Wizarding World. This project demonstrates basic game loop mechanics, random number generation, and dynamic feedback systems. It serves as a foundational exercise in conditional logic and state management for beginner developers.

Un juego de lógica divertido e interactivo en **Python** inspirado en el mundo mágico. Este proyecto demuestra mecánicas básicas de bucles de juego, generación de números aleatorios y sistemas de feedback dinámico. Sirve como ejercicio fundamental en lógica condicional y gestión de estados.

---

## ✨ Key Features | Características Clave

- **Dynamic Difficulty:** Randomized secret numbers between 1 and 30 for every new session. | *Dificultad Dinámica: Números secretos aleatorios entre 1 y 30 para cada sesión.*
- **Attempt Tracking:** Specialized logic to count user attempts and calculate a final "score" based on efficiency. | *Seguimiento de Intentos: Lógica para contar intentos y calcular una nota final.*
- **Interactive Narrative:** Themed console output (Welcome muggle!) to enhance the user experience. | *Narrativa Interactiva: Salida de consola tematizada para mejorar la experiencia.*
- **Game Lifecycle:** Handles win/loss conditions gracefully with final reveals for unsuccessful runs. | *Ciclo de Vida del Juego: Maneja condiciones de victoria/derrota con revelaciones finales.*
