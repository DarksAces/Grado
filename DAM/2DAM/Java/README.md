# 🧶 2DAM Java: Servicios Avanzados y Sistemas Multihilo

## 📋 Overview | Visión General

Welcome to the **2DAM Java Services Hub**. This directory orchestrates the most advanced track of the Java curriculum, focusing on **High-Performance Network Communication** and **Concurrent Task Processing**. The track spans from foundational multithreading theory and resource synchronization to the creation of industrial-grade **TCP/IP Socket Servers**, Custom Web Servers, and Concurrent Ticket Distribution systems.

Bienvenido al **Hub de Servicios Java de 2DAM**. Este directorio orquesta la rama más avanzada del currículo de Java, centrándose en la comunicación de red de alto rendimiento y el procesamiento concurrente.

---

## 📂 Curriculum Modules | Módulos del Currículo

- **[Servicios y procesos](Servicios%20y%20procesos/)**: The central module for systems programming. Includes high-impact laboratories in:
    - **Multithreading:** Synchronization patterns, Thread safety, and Daemon management. | *Patrones de sincronización y hilos demonio.*
    - **Network Sockets:** Custom implementations of Chat Servers, HTTP WebServers, and Concurrent Ticket Vaults. | *Implementaciones de servidores de Chat, Web y de Tickets.*
    - **Security:** Labs focusing on Secure Coding practices and mitigation of CWE vulnerabilities. | *Laboratorios de codificación segura.*

## 🛠️ Tech Stack | Tecnologías

- **Language:** Java 11/17+.
- **Network API:** Java Sockets (TCP/IP).
- **Concurrency API:** `java.util.concurrent`, `Threads`, `Atomic` operations.
- **Concepts:** Distributed Systems, RACE Conditions, Socket Multiplexing, HTTP Protocol.
