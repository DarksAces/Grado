# 🧵 ThreadSync: Laboratorio de Concurrrencia y Sincronización Avanzada

## 📋 Description | Descripción

A specialized **Advanced Java** curriculum developed in **2DAM** focused on the orchestration of concurrent processes. This directory contains a progressive laboratory track mastering the transition from sequential execution to high-performance parallel systems. Elements covered include the **Thread Lifecycle**, **Daemon Management**, and the critical implementation of **Synchronization Blocks** (Atomic operations, Monitors) to mitigate Race Conditions.

Un currículo especializado de **Java Avanzado** desarrollado en **2DAM** centrado en la orquestación de procesos concurrentes. Este directorio contiene un seguimiento de laboratorios que dominan la transición de la ejecución secuencial a sistemas paralelos de alto rendimiento.

---

## 📂 Laboratory Track | Seguimiento de Laboratorio

- **[00-01] Sequential vs Parallel:** Performance benchmarking between monolithic and concurrent architectures. | *Comparativa entre arquitecturas monolíticas y concurrentes.*
- **[02-03] State Control:** Mastery of `sleep()`, `yield()`, and `priority` orchestration, including **Daemon Thread** implementation. | *Control de estados y hilos demonio.*
- **[05] Sincronizacion:** Critical logic for shared resource management and thread safety. | *Lógica crítica para la gestión de recursos compartidos.*
