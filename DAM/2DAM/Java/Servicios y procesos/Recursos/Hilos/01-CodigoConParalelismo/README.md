## 📋 Description | Descripción

This directory contains the primary implementation of the parallel execution engine for the **ThreadLogic** track. It focuses on the orchestrated use of `Runnable` and `Thread` interfaces to achieve high-performance concurrency in Java.

Este directorio contiene la implementación primaria del motor de ejecución paralela para la rama **ThreadLogic**. Se centra en el uso orquestado de las interfaces `Runnable` y `Thread`.
