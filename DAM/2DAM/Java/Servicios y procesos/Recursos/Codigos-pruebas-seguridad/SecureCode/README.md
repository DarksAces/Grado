# SecureCode

Carpeta principal con ejemplos organizados por CWE (Common Weakness Enumeration). Cada subcarpeta contiene ejemplos `compliant` (seguros) y `noncompliant` (vulnerables), además de recursos específicos cuando aplican.

Cómo usar:

- Revisa la carpeta de la CWE que te interese (por ejemplo `CWE-664/CWE-134`) y abre los archivos `README*.md` dentro si existen.
- Ejecuta los ejemplos Python localmente desde PowerShell: `python .\ruta\al\archivo.py`.
