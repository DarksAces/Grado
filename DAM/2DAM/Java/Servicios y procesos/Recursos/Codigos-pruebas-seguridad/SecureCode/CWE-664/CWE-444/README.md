# CWE-444

Carpeta con material relacionado a `CWE-444` (inyección/entrega de payloads que pueden manipular comportamientos). Aquí hay un archivo incluido:

- `attack_payload_cl_te.txt` : ejemplo de payload usado para demostraciones o pruebas.

Advertencias y recomendaciones:

- No ejecutes ni pegues el contenido de `attack_payload_cl_te.txt` en entornos de producción ni en sistemas con datos reales.
- Usa un entorno controlado (máquina virtual o laboratorio aislado) cuando analices o tests el payload.
- Documenta los efectos esperados del payload antes de probarlo y evita acciones que puedan afectar a terceros.

Propósito: este archivo sirve como ejemplo para análisis, detección y práctica de mitigaciones frente a payloads maliciosos.
