# ValidacionAutentificacionConPostman

Carpeta con ejemplos de autenticación para probar con Postman u otras herramientas de API.

Archivos incluidos:

- `ApiKey.py` : ejemplo de uso de API Key en cabeceras.
- `BasicAuth.py` : ejemplo de autenticación básica.
- `BearerToken.py` : ejemplo con token Bearer.
- `jwt1.py` : ejemplo relacionado con JWT.

Usa estos scripts como referencia para crear peticiones en Postman o para verificar cómo funcionan distintos esquemas de autenticación.
