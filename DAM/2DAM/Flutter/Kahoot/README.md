# 📱 Kahoot Clone: App de Quizzes Multiplataforma en Flutter

## 📋 Description | Descripción

A high-performance **Flutter** application that replicates the core mechanics of a **Kahoot** quiz. This project demonstrates cross-platform state management, reactive UI design, and modular architecture using a decoupled service layer.

Una aplicación de **Flutter** de alto rendimiento que replica las mecánicas principales de un cuestionario tipo **Kahoot**. Este proyecto demuestra la gestión de estados multiplataforma, diseño de UI reactivo y arquitectura modular usando una capa de servicios desacoplada.

---

## ✨ Key Features | Características Clave

- **Reactive State Management:** Seamless coordination between the question timer, score tracking, and UI transitions. | *Gestión de Estados Reactiva: Coordinación fluida entre el temporizador de preguntas, seguimiento de puntuación y transiciones de UI.*
- **Modular Component Architecture:** Clean separation between screens (Views), widgets (Reusable UI), and services (Logic/Data). | *Arquitectura de Componentes Modular: Separación limpia entre pantallas, widgets reutilizables y servicios.*
- **Cross-Platform Compatibility:** Built to run on Android, iOS, and Web with a single codebase. | *Compatibilidad Multiplataforma: Construida para ejecutarse en Android, iOS y Web con una única base de código.*
- **Timed Logic:** Specialized quiz engine that handles countdowns and dynamic answer validation. | *Lógica Temporizada: Motor de quiz especializado que maneja cuentas regresivas y validación dinámica de respuestas.*

---

## 🛠️ Tech Stack | Tecnologías

- **Environment:** Flutter SDK
- **Language:** Dart
- **Patterns:** Service-Oriented Architecture (SOA), Provider-like states.
- **Platforms:** Android, iOS, Web, Windows.

---

## 📂 Project Structure | Estructura del Proyecto

- **`lib/main.dart`**: Application entry point and theme configuration. | *Punto de entrada de la aplicación y configuración del tema.*
- **`lib/screens/`**: Individual quiz views and navigation logic. | *Vistas individuales de quiz y lógica de navegación.*
- **`lib/services/`**: Core engine handling questions and scoring. | *Motor central que maneja las preguntas y puntuaciones.*
- **`lib/widgets/`**: Reusable UI components for consistent design. | *Componentes de UI reutilizables para un diseño consistente.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Ensure you have the **Flutter SDK** installed. | *Asegúrate de tener instalado el **Flutter SDK**.*
2.  Install dependencies: `flutter pub get`. | *Instala las dependencias.*
3.  Launch the app: `flutter run`. | *Ejecuta la aplicación.*
