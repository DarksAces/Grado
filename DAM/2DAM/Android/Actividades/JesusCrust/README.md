# ⛪ JesusCrust: The Divine Commerce App (Android)
# ⛪ JesusCrust: La App de Comercio Divino (Android)

## 📋 Description | Descripción

A high-performance **Android Native** application developed in **2DAM** using **Kotlin**. **JesusCrust** is a professional-grade mobile commerce prototype featuring a multi-activity lifecycle. It demonstrates advanced UI orchestration, secure user registration, dynamic menu rendering, and a stateful shopping cart system, all built with modern Android architectural principles.

Una aplicación **Android Nativa** de alto rendimiento desarrollada en **2DAM** usando **Kotlin**. **JesusCrust** es un prototipo de comercio móvil de grado profesional que cuenta con un ciclo de vida multi-actividad. Demuestra orquestación avanzada de UI, registro seguro de usuarios, renderizado dinámico de menús y un sistema de carrito de compras con estado.

---

## ✨ Key Features | Características Clave

- **Multi-Activity Lifecycle:** Seamless navigation between Authentication (`RegisterActivity`), Discovery (`HomeActivity`), Selection (`MenuActivity`), and Settlement (`CartActivity`). | *Ciclo de Vida Multi-Actividad: Navegación fluida entre autenticación, descubrimiento, selección y pago.*
- **Kotlin-First Logic:** Extensive use of Kotlin's concise syntax, null-safety, and modern property management. | *Lógica Kotlin-First: Uso extensivo de la sintaxis concisa de Kotlin.*
- **Secure User Onboarding:** Specialized `RegisterActivity.kt` with integrated data validation and state persistence. | *Onboarding de Usuario Seguro: Registro con validación integrada.*
- **Shopping Cart Orchestration:** Real-time management of selected items using `CartActivity.kt` and global state sync. | *Orquestación de Carrito de Compras: Gestión en tiempo real de artículos.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Kotlin.
- **Platform:** Android SDK (API 26+).
- **IDE:** Android Studio.
- **UI Components:** ConstraintLayout, Material Components, ViewBinding.

---

## 📂 Project Structure | Estructura del Proyecto

- **`MainActivity.kt`**: The application entry point and Splash/Login orchestrator. | *Punto de entrada de la aplicación.*
- **`HomeActivity.kt`**: The central discovery dashboard for users. | *Dashboard de descubrimiento central.*
- **`MenuActivity.kt`**: Dynamic product catalog with selection logic. | *Catálogo dinámico de productos.*
- **`CartActivity.kt`**: Transaction summary and item management. | *Resumen de transacciones y gestión de artículos.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the project in **Android Studio**. | *Abre el proyecto en **Android Studio**.*
2.  Install any missing SDK platforms via the SDK Manager. | *Instala las plataformas SDK que falten.*
3.  Deploy to an emulator or physical device (**Shift+F10**). | *Despliega en un emulador o dispositivo.*
4.  Experience the complete shopping flow from registration to checkout. | *Experimenta el flujo completo de compra.*
