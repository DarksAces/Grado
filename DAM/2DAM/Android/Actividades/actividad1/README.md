# 📱 Android Kotlin: Modern App Foundations (Actividad 1)
# 📱 Android Kotlin: Fundamentos de Apps Modernas (Actividad 1)

## 📋 Description | Descripción

A foundational **Android Native** project developed in **2DAM** using the **Kotlin** programming language. This module introduces the modern Android development paradigm, focusing on Activity lifecycles, UI component bindings, and the transition from Java-based legacy code to optimized Kotlin syntax.

Un proyecto fundamental de **Android Nativo** desarrollado en **2DAM** usando el lenguaje **Kotlin**. Este módulo introduce el paradigma de desarrollo moderno de Android, enfocándose en los ciclos de vida de las Actividades y la transición de Java a la sintaxis optimizada de Kotlin.

---

## ✨ Key Features | Características Clave

- **Kotlin-First Architecture:** Demonstrates the use of Kotlin's concise syntax and null-safety features in an Android environment. | *Arquitectura Kotlin-First: Demuestra el uso de la sintaxis concisa de Kotlin y la seguridad de tipos.*
- **Activity Lifecycle Management:** Core implementation of the `onCreate()` method and initial UI setup. | *Gestión del Ciclo de Vida: Implementación core de onCreate y configuración de UI.*
- **Jetpack Components:** Early usage of modern Android libraries for stable and high-performance UI rendering. | *Componentes Jetpack: Uso temprano de librerías modernas para renderizado estable.*
- **Clean Structure:** Follows the standard Android project hierarchy (manifests, java/kotlin, res). | *Estructura Limpia: Sigue la jerarquía estándar de Android.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Kotlin.
- **Platform:** Android SDK (API 26+).
- **IDE:** Android Studio.
- **Core Libraries:** AndroidX Core, AppCompat.

---

## 📂 Project Structure | Estructura del Proyecto

- **`MainActivity.kt`**: The primary entry point and UI logic container. | *El punto de entrada principal y contenedor de lógica UI.*
- **`/res/layout/`**: XML definitions for the application's visual interface. | *Definiciones XML para la interfaz visual.*
- **`/res/values/`**: Global styles, strings, and theme configurations. | *Estilos globales y configuraciones de tema.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open the project in **Android Studio**. | *Abre el proyecto en **Android Studio**.*
2.  Install the necessary SDK platforms via SDK Manager if prompted. | *Instala las plataformas SDK necesarias.*
3.  Connect an Android device or launch an AVD (Android Virtual Device). | *Conecta un dispositivo o lanza un emulador.*
4.  Build and Run (Press **Shift+F10**). | *Compila y ejecuta.*
