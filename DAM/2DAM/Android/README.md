# 📱 2DAM Android: Ecosistema Móvil Nativo y Desarrollo Avanzado

## 📋 Overview | Visión General

Welcome to the **2DAM Android Hub**. This directory orchestrates the transition into professional **Android Native** development. From foundational laboraties in activity lifecycles and navigation to the creation of high-impact clone applications (Spotify, etc.) and specialized tools (SupermarketGo), this curriculum emphasizes the mastery of **Kotlin** and the Android SDK to deliver premium mobile experiences.

Bienvenido al **Hub de Android de 2DAM**. Este directorio orquesta la transición al desarrollo nativo profesional de Android.

---

## 📂 Curriculum Modules | Módulos del Currículo

- **[Actividades](Actividades/)**: Professional-grade projects including **JesusCrust** (Ecommerce), **Spotify** (Clone), **Supermarket** (Inventory), and high-performance **Video Games** using native Canvas/View logic. | *Proyectos de grado profesional.*
- **[Ejemplos](Ejemplos/)**: A systematic laboratory track (Act1-Act5) for internalizing the Android SDK core principles. | *Seguimiento sistemático de laboratorios.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Kotlin, Java.
- **Platform:** Android SDK (Mobile).
- **Architecture:** MVVM, ViewBinding, Repository Pattern.
- **Libraries:** Retrofit, Room, Material Components, Glide.
