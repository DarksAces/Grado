# 🧪 Android Foundations: Laboratory & Activity Examples
# 🧪 Fundamentos de Android: Laboratorio y Ejemplos de Actividades

## 📋 Description | Descripción

A systematic collection of **Android Native** modules developed during **2DAM** to master the core components of the Android SDK. This repository serves as a progressive playground, moving from basic activity lifecycles and intent orchestration to advanced persistence with SQLite and API integration. Each "Actividad" represents a specific technical milestone in the mobile development curriculum.

Una colección sistemática de módulos de **Android Nativo** desarrollados durante **2DAM** para dominar los componentes core del SDK de Android. Este repositorio sirve como un campo de juego progresivo, desde ciclos de vida básicos hasta persistencia avanzada con SQLite e integración de APIs.

---

## 📂 Laboratory Modules | Módulos de Laboratorio

- **Actividad 1:** Foundational Kotlin architecture and Activity lifecycle management. | *Arquitectura Kotlin fundamental y gestión del ciclo de vida.*
- **Actividad 2:** Advanced Intent orchestration and multi-activity data exchange. | *Orquestación de Intents avanzada e intercambio de datos.*
- **Actividad 3:** UI Component mastery: Working with specialized ViewGroups and Custom Adapters. | *Maestría en componentes de UI: ViewGroups y Adapters.*
- **Actividad 4:** Data Persistence: Early integration of local storage and preference management. | *Persistencia de Datos: Integración de almacenamiento local.*
- **Actividad 5:** Final Integration: Combining all concepts into a unified proof-of-concept application. | *Integración Final: Combinación de todos los conceptos.*

---

## 🛠️ Tech Stack | Tecnologías

- **Languages:** Kotlin & Java (Hybrid).
- **Platform:** Android SDK (API 26+).
- **UI Components:** ConstraintLayout, RecyclerView, Material Design.
- **Concepts:** Intent Bundles, Lifecycle awareness, ViewBinding.

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open **Android Studio**. | *Abre **Android Studio**.*
2.  Import the specific activity subfolder as an independent project. | *Importa la carpeta de la actividad específica como proyecto independiente.*
3.  Deploy to an emulator or physical device (**Shift+F10**). | *Despliega en un emulador o dispositivo.*
