# 📱 Android Core Components: Lists, Adapters & SQLite
# 📱 Componentes Core Android: Listas, Adaptadores y SQLite

## 📋 Description | Descripción

A collection of foundational **Android Native** projects focusing on data display and persistence. Developed during **2DAM**, these activities demonstrate the evolution from simple `ListViews` to modern `RecyclerViews`, and the integration of local **SQLite** databases for secure data storage.

Una colección de proyectos fundamentales de **Android Nativo** enfocados en la visualización de datos y la persistencia. Desarrolladas durante **2DAM**, estas actividades demuestran la evolución desde `ListViews` simples hasta los modernos `RecyclerViews`, y la integración de bases de datos locales **SQLite** para el almacenamiento seguro de datos.

---

## ✨ Key Features | Características Clave

- **Modern Lists:** Implementation of `RecyclerView` for high-performance scrolling and view recycling. | *Listas Modernas: Implementación de `RecyclerView` para un desplazamiento de alto rendimiento y reciclaje de vistas.*
- **Custom Adapters:** Logic to map complex data objects to custom layout rows. | *Adaptadores Personalizados: Lógica para mapear objetos de datos complejos a filas de diseño personalizadas.*
- **Local Persistence:** CRUD operations implemented using native **SQLiteOpenHelper** for permanent data storage. | *Persistencia Local: Operaciones CRUD implementadas usando **SQLiteOpenHelper** nativo para el almacenamiento de datos permanente.*
- **UI Interaction:** Custom menus and interactive lists with click event handling. | *Interacción de UI: Menús personalizados y listas interactivas con manejo de eventos de clic.*

---

## 🛠️ Tech Stack | Tecnologías

- **Language:** Java
- **Platform:** Android SDK
- **Database:** SQLite
- **UI Components:** RecyclerView, CardView, OptionsMenu.

---

## 📂 Project Structure | Estructura del Proyecto

- **`MainListaYAdaptadoresConRecycledView`**: Modern list implementation using the Adapter pattern. | *Implementación de lista moderna usando el patrón Adapter.*
- **`mainBaseDeDatos`**: SQLite integration and data management logic. | *Integración de SQLite y lógica de gestión de datos.*
- **`mainMenu`**: Custom action bar and options menu handling. | *Manejo de la barra de acciones y menús de opciones.*

---

## 🚀 How to Run | Cómo Ejecutar

1.  Open each sub-folder as an independent project in **Android Studio**. | *Abre cada subcarpeta como un proyecto independiente en **Android Studio**.*
2.  Deploy to an emulator or physical device (API 24+). | *Despliega en un emulador o dispositivo físico.*
3.  Interact with the lists and menus to explore Android's core behaviors. | *Interactúa con las listas y menús para explorar los comportamientos core de Android.*
